# 第五部分交付包：英语学习系统

目标固定：阅读、听力、写作分别参照IELTS Academic 6.5；不做口语，不生成缺口语的官方总分。

先阅读难度变更单，然后阅读主文档。`data/`是设计参考，`materials/`是原创制作样例，`validation/`是可执行的规则示例与检查；`dependencies/`保存前四部分及第四部分任务引用供核对。旧文件不是新难度的优先来源。

运行检查：`python validation/validate_design.py`（Python 3.10+，仅标准库）。

本包不含配音、官方原题PDF、字体、真实受试者数据或英语自动评分服务。文本长度、复习间隔与证据阈值是产品初值，不是官方6.5定义。材料已登记6.5目标，但尚未完成实际难度标定。

MANIFEST.json给出相对路径与文件SHA-256；它自身不列入自身哈希。正式运行时格式与引擎由第十二部分统一。
