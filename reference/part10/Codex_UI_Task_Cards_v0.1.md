# Codex UI任务卡

目录和引擎类型待第十二部分映射，以下不授权修改上位玩法规则。每个任务交付可运行结果、错误/恢复路径、对应自动测试或真机记录；未实现部分如实列出。

## UI-DEV-01 导航与可见数据壳

**输入与依赖：**UI-01至03；上位材料访问与人物知识接口。

**输出：**六入口、24视图路由、权限先过滤、空/加载/错状态。

**禁止：**不得预加载并向UI暴露全部主线秘密；不得新增剧情条件。

**验收：**UI-AT-01, UI-AT-15, UI-AT-16, UI-AT-46。

## UI-DEV-02 输入拥有者、焦点与暂停

**输入与依赖：**UI-DEV-01；引擎输入和场景模式。

**输出：**键鼠等价、真实IME、反误触、焦点恢复、多层暂停。

**禁止：**不得直接用浏览器事件验证代替正式平台；不得让字母触发战斗。

**验收：**UI-AT-03, UI-AT-04, UI-AT-05, UI-AT-06, UI-AT-07, UI-AT-08, UI-AT-09, UI-AT-10。

## UI-DEV-03 材料与支持工作区

**输出：**原文/词典/译文、真实播放状态、显式字幕/脚本、代码点引用。

**禁止：**不得烘焙正文到背景；不得用默认朗读假装正式音轨。

**验收：**UI-AT-17, UI-AT-18, UI-AT-19, UI-AT-20, UI-AT-21, UI-AT-22。
