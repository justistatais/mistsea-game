# 1. 故事真正讲什么（STORY-01）

## 1.1 一句话故事

一名刚取得资格的巡灯人，在一次本不该发生的熄灯事故后，追查失踪导师，发现维系群岛生存的灯塔网络正在被迫以不可持续的方式运行；他必须从寻找责任人，走向验证替代方案、组织合作，并亲自承担改变系统的后果。

## 1.2 玩家目标的三次变化

| 阶段 | 玩家表面目标 | 逐渐形成的更深目标 |
|---|---|---|
| 序章—第二章 | 活下来、救人、找到导师的去向 | 分清事故、命令与被修改的记录 |
| 第三—第五章 | 查清谁做了什么，找到导师 | 不只揭发问题，还要证明其他做法是否可行 |
| 第六章—终章 | 进入第七塔，制止强制接管 | 组织一套可以实际执行、有人维护并承担责任的方案 |

第五章救出导师，不能让主线失去动力。此时玩家已经帮助过各地，亲眼见过不同生活对供能、航运和档案的依赖；即使导师建议退出，也有充分理由继续。

## 1.3 主题必须通过行动出现

本作讨论的不是“技术都是坏的”，也不是“公开所有资料就自动解决问题”。三个持续冲突是：**眼前安全与长期风险、共同调度与地方自主、公开责任与保护具体的人。**

不把主题写成连续演讲。让玩家实际面对：一份记录既能证明责任，也会暴露证人；停止超采能降低风险，却需要安置失去工作的家庭；一个聚落支持自主，但眼前仍需要邻区的电力。

英雄性来自不回避这些成本，并采取行动，而不是因为英语写得漂亮就赢得所有人的赞同。

## 1.4 冒险与情绪基调

整体基调为有危险、有损失、仍然值得修复的世界。约束不是所有人物都阴谋重重；普通人可以善良、诚实、幽默，也可以因为信息不足作出错误判断。

每章至少有一个以场景行动为中心的段落：沉船救援、地下转供站、矿井撤离、实验设施失控、旧城潜入、边境护送或中央机组处置。它们不是连续阅读之间的装饰。

每章也应有一次低压力的人物或生活场景，让玩家看见“保护城市”具体保护的是什么：渡船重新开行、修院开饭、矿工修好音乐盒、旧城街道重新挂起路牌。

# 2. 世界运行机制（STORY-02）

## 2.1 地理与生活

群岛被浓雾分割，城市、矿区与聚落依赖有限的安全航道联系。六座区域灯塔分别支撑一片主要生活区，第七座中央灯塔负责跨区调度、缓冲和主干通信。

世界仍有正常经济与日常生活：食物来自沿岸种植、林地和渔业；工业依赖矿区与学城；信件、客运、报刊、学校、剧场、工坊和家庭共同构成城市生活。不能把全部人口写成守塔者、研究员或反派。

技术风格采用机械工业与有限共鸣装置并存：金属船舶、轨道车、印刷品、有线电话、无线电式短距通信、继电器和录音设备。不存在人人随身携带的全知信息终端。

远距通信经常需要经过塔站中继，天气、设备损坏和供给安排会影响通信，但不能为制造悬念随意让同一设备上一幕无所不能、下一幕毫无作用。

## 2.2 潮晶、雾与灯塔

**潮晶**是一种虚构矿物，能从潮汐运动中缓慢积蓄可被装置利用的能量。正常开采与使用存在承载边界；长期超额抽取会损坏潮晶层，并释放更多易随空气扩散的活性微晶，加剧雾害与装置异常。

雾海本来就存在，现代系统只是放大了部分风险。因此，关闭灯塔不会让世界瞬间晴朗。

灯塔通过共鸣装置稳定附近的微晶活动，形成较安全的生活区与航道。保护作用真实有效，灯塔不是统治集团虚构的骗局。塔站提供的供能和通信也真实有用。

**需要改变的是运行方式及其治理，不是简单地把全部灯塔炸掉。**

## 2.3 三层系统要分清

| 层级 | 功能 | 改变它意味着什么 |
|---|---|---|
| 区域塔 | 本地防护、基本供能与区域通信 | 可以保留或改造，不等于必须关闭 |
| 跨区联络 | 在区域之间输送能量、共享缓冲和转发信息 | 切断后地方仍可能运行，但失去互助与调峰能力 |
| 中央强制同步 | 按中央命令将各区持续锁在统一高负荷运行状态 | 当前风险的重要来源；它不是所有同步与所有协作的统称 |

“同步”本身不自动有害。**长期超限的强制同步、过量抽取和被取消的安全步骤**共同构成问题，不能把技术风险写成“只要彼此连接就必然邪恶”。

## 2.4 为什么不能一开始就切换模式

早期区域塔有本地控制能力，但后来的改造加入了中央联锁，拆除了部分本地装置，人员也不再接受完整本地值守训练。

知道旧图纸存在，不等于已经拥有六套可用控制器。要安全改变系统，需要设备隔离、可靠控制、人员值守、供给计划及可核验的试运行。

因此主线调查会自然转为冒险：取回封存的图纸、进入危险设施、找替代零件、验证方案、护送设备、争取操作人员参与。不能让玩家在第五章读到一页说明后，按一个按钮就完成全网改革。

各章“稳定一座塔”首先表示处理该地当下危险，不自动等于完成独立运行改造。第四章形成可复用的基础改造说明，第六章再逐塔核验基础本地值守；增强分布式设备与其试运行另行登记。

## 2.5 力量体系与边界

人的战斗与探索能力来自训练、装备、可承受的共鸣负荷以及操作经验。遗物是不同年代的装置或材料，不是方便编剧随时添加新能力的许愿机。

沿用“见习巡灯人—持灯者—铭刻者—共鸣者—守望者”的候选阶位。这里仅赋予职业与社会含义；具体数值、晋升时间和技能归第七部分。

力量可以改善护盾、装置控制、危险环境适应和武器效果，但不允许全知读心、完美测谎、倒转时间、普遍复活或完整重播任何历史。旧装置保存的记录也有范围、来源和缺损，不能成为任意补剧情的全景记忆。

## 2.6 英语在世界中的身份

游戏用英语呈现通用语言。世界中的人自然地交易、工作、争论、写信与研究，不知道 IELTS，也不会询问玩家英语等级。

字典、译文、学习反馈与任务提示是玩家层面的工具，不需要强行解释成角色拥有的神奇器官。英文不是施法密码；读懂技术说明让人知道如何操作，但措辞越高级不会让机器输出越高。

## 2.7 核心术语表

| 中文 | 英文工作名 | 使用规则 |
|---|---|---|
| 雾海 | the Mist Sea | 自然环境，不能宣称终章之后永久消失 |
| 潮晶 | tideglass | 虚构材料；首次出现免费释义 |
| 巡灯人 | Beacon Warden | 跨区检修、护送与核查职业，不等于灯署武装 |
| 灯署 | Beacon Directorate | 中央协调机构，不代表全体城市的唯一政府 |
| 区域塔 | regional beacon | 玩家先理解其功能，再接触具体塔名 |
| 第七塔 | the Seventh Beacon | 中央设施，不是等待复活的神 |
| 本地运行 | local operation | 只在本地区进行控制，不自动意味着资源充足 |
| 强制同步 | forced synchronisation | 本作中特指当前超限且强制的运行政策 |
| 分布式联络 | distributed coordination | 本地控制加有边界的跨区协作，仍需规则与维护 |
| 微光号 | the Glimmer | 玩家取得的旧巡灯船，是据点，不是第一章那艘民用渡轮 |
| 镇潮机组 | the Tide Regulator | 中央大型机械装置，没有隐藏的全知人格 |

每份普通材料尽量只引入少量必要专名。学城的语言难度应来自证据、限定和论证，不来自一次出现十几个未解释的虚构词。

# 3. 地区与社会结构（STORY-03）

## 3.1 七塔对应关系

| 区域 | 区域塔 | 地区职能 | 本地的核心矛盾 | 主要探索气质 |
|---|---|---|---|---|
| 盐雾港 Saltmere | 潮门塔 Tidelock Beacon | 航运、仓储、转运与移民入口 | 维持封控还是恢复安全流动 | 码头、船舱、工坊、配电区 |
| 苔林修院 Mosswood Priory | 苔冠塔 Mosswatch Beacon | 食物、安置、抄录与独立档案 | 保护人的身份还是让责任可追查 | 林径、修院、温室、地下转供站 |
| 沉钟矿区 Drowned Bell Mines | 深井塔 Deepwell Beacon | 潮晶开采、重型零件与矿工社区 | 生计、事故风险与全网供给 | 矿井、轨道、泵房、住区 |
| 玻璃学城 Glasshaven | 棱镜塔 Prism Beacon | 研究、教育、精密制造与校准 | 承认不确定性还是迎合明确结论 | 学院、实验室、展厅、试验场 |
| 失名旧都 The Unlisted City | 归档塔 Archive Beacon | 旧行政中心、历史设施与留守社区 | 谁有权决定哪些历史继续存在 | 旧街、桥梁、封存站、扣押设施 |
| 风暴边境 Stormreach | 风脊塔 Ridgewatch Beacon | 前沿测站、边地生产与外缘防护 | 中心效率与边地基本保障 | 险路、测站、聚落、防线 |
| 中央海域 | 第七塔 Seventh Beacon | 调度、缓冲、主干联络与应急接管 | 谁能下达命令，以及命令能否被纠正 | 环形栈桥、继电层、控制层、机组 |

区域名称不等于地图只包含一个地标。修院只是苔林地区的组织中心，矿区包含家庭与市场，学城不只有实验室。

失名旧都并非无人居住的空城。沉降后，灯署把旧行政区统一列为“废弃区”，现行航图不再列出原街区名称；居民仍记得原来的生活，没有集体失忆。

主线访问顺序依据证据、可通行航线和工作能力推进，不依赖收齐六枚颜色不同的钥匙。海域方位、距离与场景通路由第三部分绘制，不能在本文凭空暗示相邻地点都能步行抵达。

## 3.2 五个主要组织

| 组织 | 它确实提供什么 | 它害怕失去什么 | 内部分歧 | 对玩家有用的资源 |
|---|---|---|---|---|
| 灯署 | 配电、维护标准、跨区通信与应急支援 | 网络崩溃和指挥失效 | 集中派、技术改革派、按命令工作但反对滥权者 | 技术人员、零件、中央设施权限 |
| 港盟 Harbour League | 航运、仓储、价格与船队协调 | 航路断裂与贸易失序 | 公共运输派与垄断获利派 | 船只、运输能力、仓储 |
| 公共档案院 Common Archive | 记录保管、身份见证与公共查验 | 档案被垄断或证人因公开受害 | 全面公开派与保护性限阅派 | 可信副本、核验程序、证人联络 |
| 玻璃学会 Glass Institute | 研究、教育、计量与精密制造 | 试验失控、声誉破产或失去资金 | 开放研究派、机构控制派、谨慎验证派 | 图纸、校准设备、独立技术评议 |
| 边地互助会 Border Compact | 地方维护、互助运输与聚落协商 | 再次被视为可牺牲的边缘负荷 | 完全自主派与有条件互助派 | 值守队、环境经验、地方协定 |

鲁克的封锁队属于灯署的安保系统，不另增一套同规模阵营。旧都居民的临时代表组织属于章节角色群体，不再开一个需要长期维护的全局声望条。

不同阵营提供不同帮助，但关键事实不能只由某阵营高好感度解锁。捐钱也不能自动换来对事实的承认。

## 3.3 玩家为什么有资格参与

巡灯人受各区域共同承认，负责设施检修、事故留证与跨区护送；并不拥有随意搜查住宅、处决官员或决定全体社会命运的权力。

第一章由港口负责人签发临时检修委托，第二章完成跨区登记，第四章取得可供独立复核的技术材料，第五章形成临时共同处置授权，第六章取得实际执行协议。

因此，玩家终章的权力来源是行动、证据和共同委托，而不是突然揭示他是第七塔唯一认可的王族后裔。不同授权路径可以改变同行人员或入口，但不能让“拒绝某阵营”变成永久主线死锁。

# 4. 固定历史与事故责任（STORY-04）

## 4.1 统一时间口径

开场熄灯事故记为 D0，以下历史时间相对 D0。剧情进展采用章节阶段，不根据现实阅读、听力或写作耗时推进灾难。

历史文书的时间固定。任务没有明确确认推进阶段时，系统不能因为玩家游玩了数小时，就让一份角色早已拿到的记录改变日期。

| 时间 | 固定事件 | 后来造成的影响 |
|---|---|---|
| 约 47—43 年前 | 长雾灾害后，六座区域塔与中央第七塔逐步连接 | 跨区合作确实救了许多人，中央体系有真实历史贡献 |
| 18 年前 | 一次严重供给危机中，玛拉参与设计短期强制同步方案 | 临时方案有效度过危机，但缺乏足够强的退出与复核保障 |
| 之后数年 | 运行上限被提高，临时状态被常态化，本地联锁逐步被中央控制取代 | 地方失去独立运行的设备与经验，系统越来越依赖高负荷调度 |
| 12 年前 | 旧都发生长期采掘相关的地层损坏与沉降，大部分人口被转移 | 当局将旧区从现行名录移除，责任记录被拆散，仍有居民留下 |
| 8 年前 | 一支港口转移船队被改派，通知与名册未正确更新 | 莉娜的弟弟此后被误列为失踪；其真实去向可在同伴支线查明 |
| 2 年前 | 奥伦在压力下签署了仍有安全旁路的检修验收 | 那批装置后来被继续使用，使应急方案失去一层实际保护 |
| 约 180 天前 | 多地异常与高抽取强度同时出现，独立研究产生警报 | 技术风险进入灯署内部讨论，而非直到终章才有人注意 |
| 约 90 天前 | 沃斯批准保留高配额，并限制不利报告的对外传播 | 她知道长期风险存在，但认为近期失供和社会冲突更迫切 |
| 约 30 天前 | 玛拉追查原始数据，发现本地控制历史与替代改造方向 | 她尚未完成全网验证，不能独自提供万能解决方案 |
| D-7 至 D-4 | 灯署批准盐雾支路断供测试；鲁克取消独立复核并压下相关警告 | 失真的住民名册让测试区域被错误视为接近清空 |
| D-4 | 玛拉通过正常检修邮务寄出材料；玩家受训路线恰好承担取件 | 她不是预知未来后选定“唯一救世主” |
| D-3 | 玛拉试图向外部核验机构递交材料，被鲁克扣押 | 官方以调查保护等说法掩盖限制人身自由的行为 |
| D-1 | 转移交接单记录玛拉仍活着，目的地使用设施代号 | 第二章能证明她当时存活，不能据此直接确认当前位置 |
| D0 | 获批测试、缺失安全复核、仍在区域内的人船与雾况共同引发事故 | 玩家所在船只搁浅；局部事故成为追查整体机制的入口 |
| 第五章末 | 鲁克拒绝移交控制，前往第七塔启动强制归一程序 | 调查进入必须处理的现实危机，但不是靠实时倒计时催玩家 |
| 终局后六个月 | 展示已选政策、地区状态与人物关系的阶段性结果 | 不宣称所有社会与环境问题永久解决 |

## 4.2 开场事故的因果必须固定

开场不是“天然灾害完全无关”，也不是“反派精准安排了所有巧合”。雾况增加事故严重程度，但断供测试与安全程序被取消具有明确的人为责任。

沃斯批准高负荷政策、此次测试与信息压制，必须承担其决策责任。鲁克为了缩短执行链条，撤销独立复核、扩大扣押并忽视警告，也承担具体责任。

基层工人可能执行过错误命令，但不能因某个维修工最后按下开关，就让上级授权链消失。反过来，也不能只因某人属于灯署，就断定其参与阴谋。

## 4.3 三次真相升级

第一层：事故不是单纯设备老化，有获批测试和被取消的保护步骤。

第二层：记录删改、配额与中央联锁使风险长期积累；掩盖者不只是盗取物资，也在维护自己认为不可失去的控制方式。

第三层：真正的替代方案不是曝光真相后自动产生，而是需要设备、检验、人员、补给和制度承诺共同实现。

终章不追加“雾海其实是一场梦”“导师其实是机器”“神明才是真正反派”等推翻此前证据的反转。

# 5. 主角、导师、对立人物与同伴（STORY-05）

## 5.1 玩家角色

玩家可自定姓名与外观，职业起点固定为新取得资格的巡灯人。可选工坊学徒、船务见习或抄录员出身，用于少量对白与角色认同；它们不是不同英语等级，也不独占主线线索。

角色可以自信、谨慎、务实或理想主义。游戏不预设玩家必然支持某个最终方案，也不让 NPC 根据语言评分推断其道德品质。

主角并非英语天赋异禀的异世界来客，不用解释为何全世界都说英语。其特殊性是走过了六地、连接了分散证据并愿意承担现场工作。

## 5.2 玛拉·维恩 Mara Venn：失踪导师

**公开身份：**资深巡灯工程师，玩家的训练导师。  
**实际经历：**十八年前临时方案的参与者，后来长期把继续运行归因于他人的修订，没有及时承担自己在设计退出机制上的不足。  
**当前目标：**停止以失真的数据作决定，完成替代方案的验证；不是证明自己永远正确。  
**盲点：**倾向相信“证据足够清楚，人就会作理性决定”，低估利益、恐惧与维护成本。

第二章让玩家看到她的早期签名，避免第五章突然用一个秘密制造廉价背叛。第五章救出后，她承认自己原始设计的局限，提供可核对的线索，并接受事实审查。

她不能在获救后接管所有推理。第六章主要协助整合方案和后方值守；她提供的关键技术信息都能由早期图纸、记录或其他技术人员独立验证。

工作对白示例：

> “I wrote the first version. They kept my signature and removed the limit. That does not erase what I failed to put in it.”

**固定状态：**从扣押到第五章获救一直存活。不设置根据玩家阅读速度决定生死的隐藏倒计时。

## 5.3 伊莱娅·沃斯 Elia Voss：灯署总监

**公开目标：**维持跨区供给，避免冬季失供与城市间的抢夺。  
**实际责任：**批准高配额、断供测试及信息压制；在收到持续高负荷风险报告后仍选择维持政策。  
**她认为自己正确之处：**互相依赖是真实的，地方不能只宣布独立就获得资源。  
**她犯错之处：**把自己的风险判断变成不可质疑的命令，并剥夺其他人检验和修正判断的机会。

第一章先通过广播和命令出现，第四章进行第一次完整交涉。她可以提出有分量的反驳，例如替代装置是否承受得住实际负荷、谁负责第一周补给。

承认她的论点有部分道理，不等于免除其责任。第五章之后，她可能作为受监督的技术协作者、证人或被停职调查者继续出现，但不能因为玩家最终保留中央调度就自动恢复“完全无辜”。

工作对白示例：

> “A city cannot live on the promise that a better system will be ready in time.”

## 5.4 加伦·鲁克 Galen Rook：封锁队指挥官

鲁克相信共同命令一旦允许地方拒绝，就无法在危机中执行。他不是暗中想统治世界的神秘教团成员，而是把应急授权扩张为永久控制的人。

其责任包括取消独立复核、压下警告、扩大扣押、阻止移交，并在第五章后启动强制归一程序。沃斯与他有分歧，但不能用“都是鲁克擅自行动”洗掉已经存在的上级授权。

终章制止鲁克、解除指挥链并将其置于看管之下，是固定主线结果。战斗失败允许重试；不通过一段自由写作自动判定处决或放走他。

最终的技术危险在其被制止后仍存在，因为设备已经进入有惯性、硬联锁与自动续启的流程。这样终章的机组处置有因果意义，而不是击败反派后突然掉下来第二个无关首领。

## 5.5 四名同伴的独立成长

| 同伴 | 加入章节与动机 | 起始信念 | 需要面对的事实 | 成长不是简单变成什么 |
|---|---|---|---|---|
| 莉娜 Lina，领航员 | 序章协作，第一章正式加入；寻找失踪家人的转移线索 | 官方记录一旦失真，所有纸面承诺都不可靠 | 有人利用改派掩盖责任，也有人保存记录帮助失散者重聚 | 学会核验而非从不信政府变成盲信另一阵营 |

正式招募是明确可见的邀请。玩家可以不将同伴编入出战队；拒绝招募时，角色仍以本地专业人士存在，在安全节点可重新邀请。

同伴有专属经历和战斗特色，但不独占任何唯一关键证据。奥伦的责任可以由仪表与工坊副本证明，莉娜的航道经验不能成为只有她才知道的主线路径。

## 5.6 同伴任务的收束方向

莉娜的弟弟在边境建立了新的生活。他当年被改派且无法正常通信，后来也因为不愿重新卷入调查而迟疑。支线允许玩家帮助通信、安排见面或尊重先保持书信联系的选择，不把“家人团聚”写成一句话完成所有裂痕。

奥伦需要修复设备、提供证词或参与长期维护安排；承担责任的方式不同，不能靠送礼抹掉已确认的签章事实。

米拉要为一份含敏感身份的材料建立保管与查验办法；公开全部、完全销毁都不应被系统自动标成高道德分。关键公共事实始终保留。

泰丝要取得设备、值守和供给的具体承诺；空泛保证不能替代物资，但争取这些承诺也不需要玩家写出某个“标准政治立场”。

同伴在结局前可以表达担心和偏好，但不能用“选我喜欢的制度，否则永久离队”充当隐形结局锁。关系数值与更细的离队边界在第九部分制定。

# 6. 八个章节的完整主线骨架（STORY-06）

以下八章组成“序章＋六个主要区域＋终章”。每章写明进入理由、玩家行动、必需揭示、局部分支与结束条件，避免只有章节标题而没有可以转化为任务的推进过程。

共设 32 个叙事节点。表中的顺序是叙事依赖的简化表达；具体探索与取证步骤可以并行，最终任务图由第四部分细化，不能照表把玩家锁在一条不可回头的走廊。

## 6.1 序章：熄灯之夜

### 开局与进入理由

玩家乘检修船前往首次任职地点。灯塔熄灭后，导航信息与实际地形不再一致，船只搁浅。开场先让玩家看见船员、货物和岸边灯光，事故打断的是一次正常旅程，而不是先讲十分钟世界史。

玩家的首要任务是离开危险区域、恢复救援联系。导师留下的箱子只是随船检修邮务中的一件物品，不能让玩家为了“重要主线道具”而无视眼前的人。

| 节点 | 玩家实际要做什么 | 必须产生的剧情进展 |
|---|---|---|
| Q-P01《断开的航线》 | 脱离搁浅船只，依据地形、潮位说明与幸存者信息建立安全路线。 | 确认熄灯发生在船只偏航之前，而不是偏航导致熄灯。 |
| Q-P02《有人还在岸上》 | 恢复岸边绞盘，安排救援并提交短求援消息。 | 认识莉娜；巡灯工作的责任先于调查欲望。 |
| Q-P03《第二个记录器》 | 恢复中继站，取得导师寄存箱和不完整的运行记录。 | 同一时刻的多个信号缺口提示需要检查公共系统，但尚不能证明人为破坏。 |

### 场景高潮与可操作内容

在浪涌间使用绞盘、固定救生索、核对地形说明，打开通往岸边中继站的安全路径。通过录音中的更正选择接应点，而不是答对词义才能拉动绞盘。

第一场战斗对抗被雾况扰动的近岸生物，说明战斗与装置操作的基本关系。战前材料提供行为线索，但普通攻击不要求答题。

### 必须留下的事实与悬念

独立记录器显示灯塔先熄灭、船才偏离原航线。现有资料足以否定“船长先违规偏航，导致所有问题”的简单归因，尚不能证明谁下令断供。

玛拉的留言要求玩家核对被要求销毁的记录。留言是人物的判断和求证请求，不作为全知旁白直接揭露阴谋。

### 输出、情绪与返回内容

玩家救出同行人员，莉娜成为共同幸存者，获得前往盐雾港的接应与导师材料。基础救援不会因为长时间阅读而自动少救一人。

情绪从惊险转为短暂安定：岸边有人点起不用中央供能的小灯。它不是已经证明全世界可以不用灯塔，而是“仍有人接住你”的人情时刻。

序章的英语输出是短求援消息；关键信息包括当前位置、人数或需求及接应约束。后续可通过港口航线返回岸边调查支线，但不再次执行整场救援。

**章节结束条件：救援通信完成，安全接应成立，独立记录与导师材料已进入证据档案。**

## 6.2 第一章：最后一班渡轮

### 进入理由与地区处境

盐雾港在事故后封港。调度负责人哈文既要避免再次出事，又面临不断累积的滞留者。玩家需要一个合法工作入口、可使用的船只，以及导师转移记录的线索。

本章不把哈文写成为了拖时长而拒绝一切帮助的人。他会接受有事实依据、能说明执行限制的方案。

| 节点 | 玩家实际要做什么 | 必须产生的剧情进展 |
|---|---|---|
| Q-101《封港令之外》 | 核对航运许可、封港令和例外，取得临时检修委托。 | 港口不是单一敌对阵营；救援与封控产生现实冲突。 |
| Q-102《最后一班渡轮》 | 整合航道公告、吃水限制、修订录音，取得支架并恢复导航灯。 | 完成撤离；给出可执行的书面方案；为事故调查取得证人与调度材料。 |
| Q-103《预先写好的事故》 | 核对签发时间、独立记录器与值班交接，发现有计划的断供测试。 | 事故不是纯粹自然故障；不能据此直接证明所有高层的具体意图。 |
| Q-104《潮门塔重启》 | 处理维护机械并恢复安全运行；获得巡灯船和跨区核查委托。 | 转往苔林核对被撤离者与导师的转移记录。 |

### 核心任务：《最后一班渡轮》

保留第一部分样章方向的事实：A 航道关闭；B 航道要求辅助泵开启，且船只吃水不超过 1.2 米；渡轮吃水为 1.4 米；C 航道开放但要求导航灯正常。待安装导航灯本体可用、支架损坏，西侧工坊有替换支架，船内有充满电的备用电池。主发电机尚未完成安全隔离，不能启动。

因此，基本可执行方案是取得支架、利用备用电池恢复导航灯并走 C 航道。不能把“修好泵”写成无视吃水约束的第二种正确答案。替代表达可接受，替代行动只有满足全部固定条件才成立。

工坊有失控维护机械。潜入、局部停机或战斗改变取得零件的过程，不改变导航信息。所有路线都保留真实的材料理解与行动确认。

### 本章揭示的限度

玩家发现测试计划早于事故，而且独立记录与调度时刻吻合。这支持“断供是预定动作”。**预先准备的事故通报本身不是蓄意制造事故的充分证据**，必须与计划、记录和被取消的检查步骤结合。

本章不提前证明沃斯知道全部环境机制，也不能仅凭签发机构就推断每名灯署人员共同谋害。

### 局部分支与成长

玩家在额外资源允许的范围内选择先修复公共渡运接驳点，或先恢复能带来更多后续运力的陆路栈桥。两者都满足本轮撤离的基本安全要求，区别在港口恢复方向与后续支线入口，不设置一句语法错误造成沉船的结算。

潮门塔稳定后，港口借出封存的旧巡灯船“微光号”，由玩家和船员逐步修复。这不是直接占用刚救援完成的民用渡轮，也不是一开始就赠送全功能移动城堡。

### 英语载体与章节出口

读航道限制、检修令与交接单；听调度更正；写撤离方案和简短核查申请。至少有一份材料在正文之外需要结合另一来源，不让所有答案集中在一张提示卡里。

本章以渡轮离港、公共交通首次恢复的小场面结束。调查线指向保存独立撤离名册的苔林修院。

**章节结束条件：撤离方案确认并执行，潮门塔恢复安全运行，获得巡灯船使用权与跨区核查委托，保存断供测试的基础证据。**

## 6.3 第二章：被删去的名字

### 进入理由与地区处境

玩家为了查找导师和事故期间被转移的人，进入苔林。这里接纳了许多不在官方现行名册上的住民；修院同时需要维护食物、住所和档案。

第一眼应当是有人生活的地方：晾晒的衣物、排队领餐、温室工作和孩子归还书本，而不是一座只为藏谜题而存在的阴森书库。

| 节点 | 玩家实际要做什么 | 必须产生的剧情进展 |
|---|---|---|
| Q-201《没有登记的住民》 | 走访修院与临时住地，比较口粮、住址和官方名册。 | 官方死亡或迁出标签不一定代表实际去向。 |
| Q-202《第二份撤离名单》 | 重建转移时间线，区分身份保护记录与掩盖事故的删改。 | 导师在开场前一天的转移交接时仍活着；这不是其当前存活的独立证明。 |
| Q-203《林下的转供站》 | 修复地下供能站，比较旧式本地运行图和新式中央联锁。 | 本地运行在物理上可行，但现有各塔并未完成安全改造。 |
| Q-204《谁可以知道这些名字》 | 确认公开、限阅和身份保护范围，提交事实摘要。 | 发现导师参与过临时强制同步方案；取得矿区检修批次线索。 |

### 核心冒险与情节转折

林下转供站被根系、积水与失控装置共同阻断。玩家要进入地下空间，对照旧说明恢复局部供能，并处理环境适应型生物或失控机械。

这段行动证明某种本地运行确实能够成立，但设备规模小、负荷有限，不能据此断定六座现代灯塔可以直接拔掉中央接线。

档案调查揭示两种不同删改：有人删除姓名是为了逃避事故责任，也有人暂时隐藏身份以保护住民。相同行为表面不等于相同动机，必须看记录用途与实际后果。

### 导师线与同伴线

转移交接单证明玛拉在 D-1 仍活着，目的地是设施代号。玩家此时不能把“当时活着”误写成“现在肯定安全”。第二章得到的矿区批次号提供下一步核查方向。

另一份旧方案出现玛拉的签名。她曾参与中央临时方案是需要继续核实的线索，而不是系统突然把她标成幕后主谋。

米拉在此加入或成为可反复拜访的专业联系人；莉娜可以取得弟弟转移记录的一部分，同伴任务不阻断主线。

### 公开范围选择

玩家确认是否发布脱敏公共摘要、提交受托审查，或在取得相关人明确同意后公开具体身份。关键公共事实必须在审查体系中可核验；不能因为选择保护身份就被系统判为包庇。

该选择影响证人愿意参与的方式、区域来信和后续人物反应，不更改谁实际上做过什么。

### 英语载体与章节出口

读名册、书信、旧运行图与带修订痕迹的记录；听不完全一致的证词；写能够说明事实、未知部分和访问范围的申请或摘要。

章节的安静时刻是用修好的供能站维持一场晚餐。玩家见到名册上曾被划去的人正在吃饭，这比旁白强调“记录很重要”更有意义。

**章节结束条件：取得可核验的转移链、稳定苔冠塔与本地支站、明确档案访问安排，并获得矿区检修批次线索。**

## 6.4 第三章：地下的代价

### 进入理由与地区处境

检修批次号把玩家引向沉钟矿区。矿工既受超采威胁，又依赖矿业收入，其他地区也依赖这里的材料和能源。

本章不能让矿工只在“贪婪污染者”与“被动受害者”之间二选一。领班佩拉会要求玩家说明：停止一段生产之后，设备、住户和工资如何安排。

| 节点 | 玩家实际要做什么 | 必须产生的剧情进展 |
|---|---|---|
| Q-301《钟声以下》 | 进入矿井修复通路、寻找被困工人并核对环境记录。 | 当前超采与危险异常同时存在，但相关不等于完整因果证明。 |
| Q-302《最后一道检修章》 | 比对原始仪表、工坊副本与正式签章，处理奥伦的责任。 | 未修复的安全旁路曾被作为合格工程交付。 |
| Q-303《三炉一线》 | 满足基本安全约束后，在居民安置、生产与改造中安排额外资源。 | 资源选择改变地方条件，不由语法分数决定。 |
| Q-304《停止超采》 | 执行降载或明确限期的过渡供能方案，稳定深井塔。 | 配额、抽取强度与异常之间存在可追查链条，需要到学城进行技术核验。 |

### 核心冒险

玩家进入下沉矿层，恢复泵房和轨道，寻找被困人员。任务材料包括班表、旁路记录、仪表读数和维修工单，它们决定哪些通道可进入、哪段设备应先隔离。

战斗与危险集中在失控开采装置、雾害生物以及少量阻碍调查的安保人员。不能把一场劳资争议的唯一解决方案设成打倒所有工人。

### 奥伦与事故责任

奥伦承认自己签署过不实验收，但他的口供不是唯一证据。现场仪表、工坊留存副本和正式验收版本能够组成独立核查路径；不招募他也能查明事实。

玩家可以选择要求其公开证言、先参与限期修复并在监督下补交说明，或交由地区核查。不同安排改变同伴关系与人手，不会把伪造验收自动改写成没有发生。

### 资源选择的边界

首先完成基本撤离和安全保障，再安排额外资源。可以尽早降低抽取并投入住民安置，也可以维持一个明确限期、有限负荷且有值守的过渡供给窗口，为设备与物资转移争取条件。

“继续不设上限地超采”不作为与前两者同样安全的隐藏正确解。玩家若选择承担已说明的额外风险，必须通过明确行动确认；这里的正式主线可行方案仍保留可恢复的安全边界。

### 揭示、载体与出口

本章取得配额—开采—安全旁路—环境异常的连续记录。它提出可检验的因果假设，而不是仅看到两条曲线同时升高就宣布所有科学争议结束。

读设备说明、维修与供给文件；听领班、工程师和调度人员的讨论；写事故摘要或资源安排。情绪收束可以是一台停工后的机器安静下来，以及人们开始讨论下一周如何生活。

深井塔稳定后，玩家携样本与记录进入学城；沃斯也通过正式渠道要求核验，让她成为试图把调查纳入控制的人，而非只在结尾登场的名字。

**章节结束条件：矿井安全问题得到处置，检修责任链可核查，地区供给方案确认，取得前往学城验证的材料。**

## 6.5 第四章：玻璃学城

### 进入理由与地区处境

玩家带着矿区材料来到学城，希望得到“问题是什么、还有没有别的办法”的答案。学会不同团队分别受到资金、声誉和试验风险约束，不应被写成一个全体撒谎的组织。

本章开始要承认玩家已经掌握部分真相，但仍缺少可靠的替代方案。研究员西安对灯署和玩家提出同样的验证要求。

| 节点 | 玩家实际要做什么 | 必须产生的剧情进展 |
|---|---|---|
| Q-401《相同的曲线》 | 比对独立采样、地点条件和公开报告，建立可检验假设。 | 灯署报告删去了不利结果，但仅发现删改尚不能证明替代方案安全。 |
| Q-402《在场的反例》 | 复原失败试验，排除不适用于高负荷场景的方案。 | 停止过载不会马上清雾；局部试验不能证明全网可靠。 |
| Q-403《孤网试验》 | 配置并观察有限负荷下的本地控制和联络隔离试验。 | 验证受限条件下的替代控制办法，并记录适用边界。 |
| Q-404《不完整的答案》 | 提交包含证据、限制与风险的方案，与沃斯直接交涉。 | 沃斯已知道持续高负荷具有长期风险；导师被扣押地点指向旧都北站。 |

### 三组必须出现的材料

第一组是不同地点、不同负荷的观测数据，用于辨认值得检验的关联。第二组是删改前后的报告，用于确认信息被如何呈现。第三组是有正例与失败例的受控试验记录，用于界定方案的实际适用范围。

关键结论不是“分布式一定完美”，而是：在规定负荷、隔离配置与值守条件下，本地控制加有限联络能够运行；高负荷、错误隔离或缺乏备用供给时会出现已知失败方式。

### 核心行动

玩家进入旧试验设施，复原一套失败装置，再布置或校准小规模孤网试验。过程中包含设备操作、危险隔离和失控装置处置，不能全章坐在桌前读图表。

试验步骤与结果固定，不让 AI 临时生成一个恰好支持玩家立场的数据集。正反材料都可保存并回看。

### 与沃斯的第一次完整交涉

沃斯承认未来风险需要处理，但要求玩家回答转型第一周的供能、人手与跨区责任。她试图要求延后公开并继续集中控制；玩家可以认可部分技术担忧，同时反对她剥夺复核的做法。

写作任务可以是带限制条件的比较报告。人物回应取决于玩家明确提出的事实与承诺，不因其采用某种政治观点或较简单句式而自动失败。

### 下一阶段的明确准备表

试验后还要完成棱镜塔的安全降载与基础核查。局部试验、塔站当前安全和六塔完整转型是不同层次，不能因为在学城成功启动一次小装置，就把所有塔标为准备完成。

本章结束时已经向玩家展示分布式路线需要：验证后的方案、六塔改造、过渡供给、共同协议和现场试运行。它们是公开的转型准备目标，不是终章突然宣布漏做的隐藏支线。

玛拉被扣押的具体地点通过设施代号、物资去向和看守记录交叉定位到旧都北站。玩家不需要靠最高感知找到唯一小纸条。

**章节结束条件：技术假设经受正反验证，替代方案的适用边界记录清楚，取得导师扣押地点，完成棱镜塔安全核查，并开放转型准备清单。**

## 6.6 第五章：谁有权记录真相

### 进入理由与地区处境

玩家进入现行地图上被统一标记为废弃区的旧都。居民还在经营、维修和守护家园，灯署的封控与鲁克的扣押设施嵌在这些真实生活空间之中。

旧地图不只是密码图。它与现在的桥梁、沉降地段和居民新开的通路相互补充，支持实际穿行与探索。

| 节点 | 玩家实际要做什么 | 必须产生的剧情进展 |
|---|---|---|
| Q-501《从地图上消失的街道》 | 结合旧地图与居民记录穿过旧都，寻找被接管的北站。 | 旧都被行政除名，居民没有集体失忆。 |
| Q-502《灯下的人》 | 进入扣押设施并救出导师；任务失败可重试。 | 导师存活成为当前直接事实；其证词不是唯一核心证据。 |
| Q-503《十八年前的签名》 | 交叉检查旧方案、后续修订与现行命令，组织有反证机会的审查。 | 导师、沃斯与鲁克承担不同的具体责任，不能互相替代或抵消。 |
| Q-504《谁来接管》 | 确认临时保管、公开范围和过渡监督安排，稳定旧都塔。 | 鲁克拒绝移交，抢先进入第七塔执行强制归一程序；调查转入危机处置。 |

### 先救到人，再处理责任

在北站设施中，玩家通过检修通路、证件核查和必要战斗救出玛拉。失败回到适当检查点；她不会因为玩家读了太久档案而在后台死亡。

她解释十八年前的方案和后来的修订，但玩家仍需比对原始设计、会议记录、执行副本和独立材料。她的证词可以增加理解，不能代替之前所有调查。

### 本章的责任图

玛拉负责原始设计中的不足及后来未及时纠正的部分；沃斯负责已知风险下的高配额、测试授权与信息压制；鲁克负责取消复核、扩大扣押及拒绝移交等执行行为。

这三种责任可以同时成立。不能把玛拉写成“原来她才是一切元凶”，也不能把鲁克写成替全体上级背锅的方便反派。

### 审查与接管不是一篇作文决定社会

玩家组织的是带有材料、交叉核验和反证机会的紧急公开或受保护审查。自由写作承担整理证据与提出要求的功能；最终决定使用固定事实、已确认主张和参与方明确同意的程序。

玩家选择暂时由谁保管原始档案、哪些内容向公众公开、过渡设施由哪些代表共同监督。中央方案、断联方案或分布式方案都不应在这里因“支持了错误阵营”而被暗中永久排除。

### 转折与出口

归档塔得到稳定，基础档案与已收集证据保存。鲁克拒绝交出指挥权，并抢先进入第七塔，准备将当前应急状态锁为强制归一程序。

沃斯不能继续控制全部事实，可以配合受监督的技术处置，也可以被停职；她对网络互相依赖的了解仍有价值，但不构成独占解法。

本章安静场面是玛拉读到玩家保存的早期材料，发现学生不仅找到她，也找到了她不愿面对的责任。

**章节结束条件：导师获救，关键责任关系完成核验，归档塔恢复安全，形成临时共同处置授权，并确认鲁克已转向中央设施。**

## 6.7 第六章：风暴边境

### 进入理由与地区处境

边境测站掌握当前雾况与中央程序相互影响的信息，风脊塔也是最后一座尚未完成联合安全核查的区域塔。玩家必须在这里把研究方案变成行动能力。

泰丝和物资协调员芬要求看到具体设备、值守表与供给安排。不能只通过一句“我承诺照顾边地”就取得无限人力。

| 节点 | 玩家实际要做什么 | 必须产生的剧情进展 |
|---|---|---|
| Q-601《最后的测站》 | 抵达暴露在浓雾中的测站，取得当前网络风险与供给边界。 | 风暴将放大危险，具体行动窗口由剧情阶段而非现实读写速度推进。 |
| Q-602《六个答复》 | 逐一确认六塔基础值守与备用运行能力，处理转型准备中的缺项。 | 基本保全和分布式升级是两套不同的准备清单。 |
| Q-603《风脊线》 | 护送设备、维护风脊塔并组织边地防守。 | 完成基础保全；地方公平问题不能用一句支持独立解决。 |
| Q-604《起航之前》 | 核对方案资格、人员、供给、协议及未完成事项，确认进入终章。 | 未满足的分布式条件必须提前列明，可在起航前补齐；不能到最终按钮才揭露。 |

### 两套准备不能混为一谈

**基础保全准备**是所有主线玩家都会完成的：六塔具备最低本地值守、必要隔离、应急补给与通信安排。它确保终章至少有中央受限运行和有序断联两条可执行路线。

**分布式转型准备**是玩家明确选择投入的工作：安装增强控制与联络装置，准备转换阶段供给，确定六地操作方与代表接受的协议，完成现场试运行。它不是六枚神秘钥匙，而是六地真实具备工作能力。

所有准备条件从第四章起可见，并提供按材料、人员、运输和协议分类的缺项。技术员和操作人员可以来自区域团队，不要求带齐四名可招募同伴。

### 核心冒险

测站调查、风脊线设备护送和防线维护形成本章主要行动。封锁队试图优先保障中央征调，雾害又威胁外缘路线；玩家需要选择可执行的路径与保护安排。

资源分配可在满足基本安全后偏向覆盖更多集中人口，或改善分散聚落的最低保障。后果体现于运输、安置与重建，而不是一段英语错误随机扣除聚落人口。

### 起航前的资格检查

Q-604 明确展示可执行方案与缺项，允许返回各地或委托已建立的队伍完成相应准备。委托必须有具名或已登记人员、资源和任务，不凭空生成“后台自动修好全部塔”。

进入终章前确认区域暂时不可重访的范围，保留存档。未做足分布式准备的玩家会明确看到该路线尚不具备条件，并可以选择继续准备或接受另外两种方案；不能直到最终按钮才告知。

这段不使用真实时间截止。风暴与强制程序通过确认进入下一剧情阶段推进，保留读写与思考的时间。

### 情绪与出口

收到六个不同地点的回执，既有正式电报，也有简短的个人留言。玩家看到沿途的工作确实变成了参与行动的人，而不是所有地区只在结局字幕出现。

**章节结束条件：六塔基础保全到位，风脊塔稳定，准备资格与缺项向玩家可见，起航获得明确确认。**

## 6.8 终章：第七座灯塔

### 进入理由与结构

玩家携带已确认的共同处置授权和实际准备进入第七塔。终章依次解决“谁控制现场”“危险程序能否停止”“接下来采用什么安排”，不能将三者混成一次战斗胜负或一次作文评分。

| 节点 | 玩家实际要做什么 | 必须产生的剧情进展 |
|---|---|---|
| Q-F01《进入第七塔》 | 采用检修通道或受承认的移交通道抵达中央设施。 | 路线改变场景与战术，不改变核心事实。 |
| Q-F02《接管层》 | 制止鲁克并解除其指挥链，取得中央现场控制。 | 制止执行者不等于已经停止惯性运行的危险程序。 |
| Q-F03《不可取消的维护》 | 通过解谜与战斗稳定镇潮机组，解除强制同步程序的自动续启。 | 先建立可选择的安全状态，随后才执行政策方向。 |
| Q-F04《最后一份命令》 | 选择符合准备条件的方案，写出并确认关键指令，再由规则执行。 | 结局来自确认行动与准备，不来自措辞、观点或语言评分。 |
| Q-F05《之后还有灯》 | 查看即时结果与六个月后的地区、人物和档案后果。 | 无方案能立刻清除自然雾海；结局不是学习能力认证。 |

### 第一阶段：进入与接管

有合作安排时，可以通过认可临时授权的值守人员进入部分区域；另一条路径使用既有检修通道。路线影响部分场景和战术，不让失去某个阵营好感的玩家无路可走。

在接管层制止鲁克、解除其指挥链。关键事实已在之前章节建立，这里不靠反派临死前一次讲完全部真相。

### 第二阶段：镇潮机组

机组已经进入危险维护循环。玩家需要读取现场指令与状态，结合装置操作和回合制战斗，建立不再自动续启的稳定状态。

这不是一个突然产生恶意的人工智能。机械行为来自固化安全条款之间的冲突、被提高的阈值和现实硬件惯性。停下它需要现场操作，不能只让鲁克说一句“取消”。

具体阶段、敌人技能与机关时序由第六、第八部分细化。阅读资料时暂停惩罚性计时。

### 第三阶段：最后一份命令

先展示当前可执行方案、已知限制、地区准备和关键后果，再让玩家选择方向并撰写行动说明。系统确认自己理解到的行动，必要时提供澄清或辅助整理。

任务应区分“解释不够清楚”和“方案不满足事实条件”。使用字幕、译文、低战斗难度或受控草稿，不能取消任何已经具备条件的结局。

不在最终界面新加隐藏条件、保密词组、好感阈值或精确字数。技术资格不由 AI 文风评分给出。离线或无法可靠评价时，通过结构化行动确认继续执行，语言记录保持“尚未评估”，不把未获得的写作证据补成通过。

### 第四阶段：结果与尾声

先看即时动作：各塔如何切换、谁开始执行、哪些运输与供给受到影响。随后展示六个月后的地区卡片、同伴来信与公共档案结果。

不为三个结局各做一套完整开放世界。使用共用地点的状态变化、少量新场景、文字与音频回执形成可感知的差异。

通关后提供清楚标记的“终局前存档继续探索”，不让回到旧地图自动改写已经保存的结局快照。重打另一结局属于另一条冒险结果，学习接触历史仍然如实保留。

**章节结束条件：现场危险程序被稳定，行动方向明确确认并执行，结局快照生成，学习总结与剧情评价分开显示。**

# 7. 真相、证据与知识权限（STORY-07）

## 7.1 四个信息层

创作者知道的世界事实、玩家目前已取得的证据、NPC 的认知、NPC 对外的说法，必须分别记录。

例如，制作资料从开始就知道玛拉活着；序章玩家只知道她失联；第二章知道她在 D-1 的交接中存活；第五章才见到当前活着的她。不能因为任务系统读取了制作资料，就让第二章任务简介写“去营救仍然安全的导师”。

章节进度只能表示通常的揭示上限，不自动授予未取得材料的知识。玩家假设也不能直接写入“已证实事实”。

## 7.2 主线证据登记

下表给出最低的证据关系，不是每份英文材料的终稿。复杂责任与系统性结论需要异源核验；简单的现场功能、清楚的通行限制和直接见到某人，并非机械要求都做成两份材料。

| 编号 | 要支持的命题 | 主要证据 | 独立核验或访问兜底 | 最迟需要出现 |
|---|---|---|---|---|
| E-01 | 开场断供包含预定测试，而非单一自然故障 | 测试计划、控制时刻与独立记录器 | 港口交接记录；已取得材料的固定档案副本 | Q-103—Q-104 |
| E-02 | 官方住民标签不能准确代表所有人的实际去向 | 名册、现场住民、口粮与住址记录 | 修院原始接收登记、其他在场见证 | Q-201—Q-202 |
| E-03 | 玛拉在 D-1 转移交接时还活着 | 带时间与交接人的转移单 | 经核验的看守交接记录；不直接推断当前状态 | Q-202 |
| E-04 | 本地控制具有物理可行性，现代设备仍需改造 | 旧接线图、转供站现场恢复 | 可观察的局部运行结果与另一份维护说明 | Q-203 |
| E-05 | 不安全设备曾被按合格验收 | 正式验收版本、现场安全旁路 | 工坊留存副本与仪表；奥伦证言只增加信息 | Q-302 |
| E-06 | 超限抽取与风险存在可检验的因果依据及适用范围 | 分地观测、受控试验与失败记录 | 独立采样、现场检查和被保留的反例 | Q-401—Q-403 |
| E-07 | 对外报告删去了已知不利内容 | 同版本原稿、发行稿与流转记录 | 保管方的版本记录；不能把不同日期的正常更新误作删改 | Q-404 |
| E-08 | 玛拉参与早期临时方案且承担特定设计责任 | 原始方案、会议记录与变更历史 | 作者签章核验、早期设施资料 | Q-503，第二章已有伏笔 |
| E-09 | 沃斯批准了相关政策并限制风险信息传播 | 当前授权链、配额、报告接收与限制指令 | 其他部门保留的执行记录与可质询的证言 | Q-503 |
| E-10 | 鲁克取消复核、扩大扣押并阻碍移交 | 交接、扣押与检查步骤变更记录 | 不依赖其本人承认；原执行人员和异地留存材料可核验 | Q-503—Q-504 |
| E-11 | 分布式实施必须满足明确条件 | 试验边界、设备清单与共同协议草案 | 选择该路线时逐塔取得现场试运行回执 | 条件在 Q-404 公布；实施依据在 Q-604 前核验 |
| E-12 | 制止鲁克后，危险程序不会自行终止 | 中央指令记录、自动续启规则、现场状态 | 可观察的机组反馈与操作结果 | Q-F02—Q-F03 |

**备份不等于独立来源。** 同一份报告复制两次，只解决访问与丢失问题，不能当作两份互相印证的证据。

重要证据可以固定保存、由可信保管方提供副本或重新调查取回；不能通过随机掉落、指定同伴、特定属性或一次错过的限时对话作为唯一获取路径。

## 7.3 主要人物的知识边界

| 人物 | 一开始实际知道 | 起初不知道或没有验证 | 允许隐瞒但必须留痕的内容 |
|---|---|---|---|
| 玛拉 | 自己的历史参与、风险报告、存在替代方向 | 六塔全规模转型是否可可靠实施 | 自己对早期方案的责任；不得让她一直假装毫不知情 |
| 沃斯 | 高配额风险、报告争议、当前依赖与测试授权 | 鲁克每一步执行细节、替代方案在当前全网的实际完成度 | 已决定限制传播的材料、继续运行的真实理由 |
| 鲁克 | 自己的命令、扣押、中央接管程序 | 全部生态机制和所有试验细节 | 撤销复核、扩大权限与拒绝移交 |
| 莉娜 | 航运经验、家人失联与船队异常 | 灯塔机制和弟弟完整经历 | 个别私人恐惧，不掌握隐藏全局解法 |
| 奥伦 | 自己签过的验收及设备问题 | 全部高层授权、各地区真实负荷 | 自己的签章行为，不得让其用技术失忆逃避责任 |
| 米拉 | 档案保管与部分身份保护安排 | 完整事故原因、所有转移目的地 | 敏感身份；公开公共事实并不自动要求泄露全部私人信息 |
| 泰丝 | 边地供给与环境风险 | 中央完整指令和试验有效范围 | 地方内部的分歧，不掌握一键独立的秘密技术 |

人物可以误解、犹豫或修正观点。对话写作要区别“不知道”“知道但不愿说”“认为如此但不确定”，不能全用省略号制造悬疑。

## 7.4 允许的误导与禁止的欺骗

可以让玩家先怀疑自然故障、基层破坏或导师参与了当前事故，但必须有合理理由，也有能检验这些假设的材料。

不能在玩家找到证据之后，根据其猜测动态更换真正的责任人。不能把正常记忆误差、口音或表达困难直接当成撒谎证据。

大反转揭示的是已有事实的联系，不是终章才加入此前没有任何可能得知的世界规则。

# 8. 章节中的读、听、写与生活内容（STORY-08）

本节分配叙事载体与使用目的，不提前标定语言等级、词数、得分阈值或完整能力模型。这些由第五部分统一。

| 章节 | 主要阅读 | 主要听力 | 真实书面产出 | 不依赖长文的冒险段落 |
|---|---|---|---|---|
| 序章 | 航线与设备说明、短消息 | 求援、位置更正 | 短求援消息 | 绞盘救援、中继站恢复 |
| 第一章 | 公告、限制、交接与测试计划 | 调度修订与船员回报 | 撤离指令、核查申请 | 工坊进入、渡轮修复、塔站战斗 |
| 第二章 | 名册、书信、旧图纸与记录修订 | 证词与身份说明 | 有范围限制的查询、事实摘要 | 林径与地下转供站 |
| 第三章 | 班表、工单、验收、供给与仪表 | 多方工作讨论 | 事故摘要、调配方案 | 矿井与轨道救援 |
| 第四章 | 完整研究、比较数据、试验边界 | 讲解、异议与技术交涉 | 比较报告及不确定性说明 | 试验设施复原与现场处置 |
| 第五章 | 版本链、授权、会议记录与历史叙述 | 可交叉质询的证言 | 证据摘要、审查要求 | 旧城穿行、设施潜入与营救 |
| 第六章 | 风险简报、维护、物资与协议 | 多地通信和行动回执 | 联合行动安排 | 测站、护送与防线维护 |
| 终章 | 指令、状态与转换方案 | 中央回报与地区确认 | 最终行动说明 | 进入、接管与镇潮机组处置 |

不是每章都写同一种“事故报告”。请求、叙述、比较、说明、论证与程序性指令应轮换出现。信件、日记、旅行记录与社会生活文章提供不同语域，避免全部英语像设备手册。

较长文章必须与调查目标相关，并允许整体阅读与回看，不能把所有难度都拆成互不联系的便条。技术专名提供解释，推理依赖文本中可获得的事实，不依赖玩家现实中的航海、工程或专业学科知识。

## 8.1 十二个支线种子

这些是后续可展开的剧情种子，不表示十二个完整关卡已经制作。它们不改变固定历史或主线责任，不强迫所有支线都连到中央阴谋。

| 地区 | 支线种子 | 玩家要面对的具体问题 | 可保留的局部结果 |
|---|---|---|---|
| 盐雾港 | 同一间房 | 延误客人与新订房发生冲突，核对日期、承诺和替代住宿 | 不同安置办法、来信与小额资源变化 |
| 盐雾港 | 最后一场戏 | 恢复一场因停供取消的小演出，比较设备、时间与道具需求 | 剧场重新开放或改为小规模演出；不要求玩家说台词 |
| 苔林 | 没寄出的回信 | 作者改变了想传达的意思，玩家需理解草稿与收信人的关系 | 帮助重写、暂存或改为简短确认 |
| 苔林 | 冬季种子 | 比较种植说明、储存记录与有限温室空间 | 两种有不同短期产出的配置，不存在一句万能答案 |
| 矿区 | 修好的音乐盒 | 从维修便条与一段旧录音定位缺失部件 | 归还原主、放进公共休息室或保留待寻人 |
| 矿区 | 换班的人 | 班表、口头承诺和家庭安排冲突 | 重新分工或获得额外人手，避免把问题都变成抓坏人 |
| 学城 | 没有署名的人 | 一项小发明的贡献记录不完整 | 补记贡献、联合展示或暂缓发表 |
| 学城 | 新来的学生 | 招生说明与课程安排让转学者误解了实际要求 | 帮助制定可行安排；不设置玩家代考 |
| 旧都 | 给街道一个名字 | 居民对恢复旧名或保留新名有不同记忆 | 明确的命名方案与小范围场景标识变化 |
| 旧都 | 失物不是证据 | 一件私人纪念物被误当作公共案件材料 | 在不破坏真正证据链的前提下确认归属 |
| 边境 | 两个天气预报 | 两个虚构预报采用不同窗口和地点，需安排一趟运输 | 选择路线与备用办法；不让现实游玩时间决定灾难 |
| 边境 | 借来的灯 | 相邻聚落争执共享设备的归还、保养与替代供给 | 形成有限互助或各自安排，留下后续回执 |

## 8.2 微光号上的持续内容

微光号承接修理、来信、同伴生活和档案复盘。它的变化来自实际冒险：有人带来旧椅子，有地方送来食物，船上新增工作台或能收听远处塔站的设备。

营地事件可以复现语言点，但也需要人物目的。来信不应每次都故意写错语法等待玩家批改；有些只是告知结果、分享生活或提出新请求。

大规模事件生成优先扩充这些低耦合内容，不允许新增支线突然宣布已经获救的导师其实早已死亡。

# 9. 分支结构与可管理的世界状态（STORY-09）

## 9.1 主线总体结构

采用“章节骨架固定、区域内方法与局部后果可变、终章三类政策方向”的结构。每个章节出口保证下一章能成立，但玩家仍然能看见此前选择对人物、供给、可选路线和地区恢复的影响。

不为每次选择制作完整的新章节，也不把所有选择都收敛成一句无后果对白。

本版建议每个主要地区保留一个明显的主线政策选择、若干方法选择和少量支线状态。最终字段由第四、第九和第十二部分统一。

## 9.2 主要选择及其影响

| 地点 | 选择对象 | 当下可见变化 | 后续可见变化 | 不能改变什么 |
|---|---|---|---|---|
| 盐雾港 | 额外修复优先放在渡运接驳或陆路栈桥 | 工人、交通与可访问支线变化 | 运力、撤离安排与区域回执 | 已确认的航道限制与事故责任 |
| 苔林 | 资料的公开范围与身份保护 | 谁愿意以什么形式参与 | 证人信任、来信、审查形式 | 人物真实去向与公共证据存在性 |
| 矿区 | 降载节奏与基本保障之后的资源安排 | 生产、安置与可用人手 | 改造速度、材料成本与地区生活 | 不安全验收曾发生的事实 |
| 学城 | 经核验材料如何传播和接受复核 | 参与验证的机构与公众反应 | 技术合作方式、访问手续 | 试验数据、失败边界与必要准备 |
| 旧都 | 临时档案保管与设施监督 | 现场权限、合作人员 | 问责与公众参与形式 | 已核验的作者、命令和行为 |
| 边境 | 满足基础安全后的运输与供给重点 | 护送顺序、安置地点 | 中心效率、外缘保障与重建速度 | 所有基础可行方案必须满足的保全要求 |

公开范围按材料或材料组管理，不用一个全局“公开度 80”自动向所有人透露所有信息。阵营关系可影响沟通方式，但明确的实施条件不能变成隐藏好感分数。

## 9.3 十二类语义状态

这些名称只用于设计沟通，不是允许 Codex 直接定稿的数据库字段。

| 状态域 | 必须表达的含义 |
|---|---|
| 章节阶段 | 当前节点与已满足的叙事依赖 |
| 已取得证据 | 内容来源、版本、持有状态、哪些结论已被核验 |
| 材料访问 | 已公开、脱敏公开、受托限阅或私人保管的范围 |
| 六塔状态 | 基础本地保全、增强改造与现场试运行分别记录 |
| 转型准备 | 技术包、设备、过渡供给、共同协议、试运行的实际状态 |
| 地区结果 | 六地的有限政策选择与恢复状态 |
| 临时授权 | 授权范围、参与方与保管责任 |
| 支援承诺 | 哪个队伍提供什么资源，在什么条件下履约 |
| 同伴经历 | 个人任务与关系事件，不直接决定结局资格 |
| 责任记录 | 已核验的行为与审查结果，不能被好感或结局方向擦除 |
| 最终行动 | 尚未选择或已确认的三类方案之一 |
| 结局快照 | 终局提交时的世界状态与尾声片段来源 |

地区结果、人物回应与结局文本组合显示，不为所有状态组合写一份独立长篇结局。组合时要按事实生成兼容片段：选择断联后，某封信不能继续描述中央每天无条件调配全部地区。

# 10. 三类结局及可执行条件（STORY-10）

## 10.1 先稳定，再选择

所有正常主线玩家在最终决定前都会完成两件事：六塔的基础本地保全安排；第七塔危险程序的现场稳定。

这保证至少存在两种可执行方向。玩家选择分布式改造，需要额外的、从第四章起就可见的准备。

概念资格规则如下：

```text
基础条件 = 中央危险程序已稳定 且 六塔基础保全到位

受限中央调度可选 = 基础条件
有序断开中央联络可选 = 基础条件
分布式联络可选 = 基础条件
                 且 技术包通过规定验证
                 且 六塔增强装置安装完成
                 且 转换阶段供给就绪
                 且 六地操作与代表方接受共同协议
                 且 六塔现场试运行通过
```

“共同协议”不是要求五个阵营好感度都到最高。它要求具体操作方与地区代表就最低保障、故障隔离、日志查验、争议处理和维护责任达成明确安排。

技术包验证与现场试运行不是重复：前者验证方案在说明的条件下可行；后者确认这六座实际设备及其值守已经达到该条件。

装备安装完成也不等于转换阶段物资足够。后者涵盖切换期间的必要供给与缓冲，具体数量交给任务、经济和技术部分共同确定。

结局资格不读取英语成绩、字数、字幕、翻译、提示次数、战斗难度、隐形道德分或某个同伴是否在队。

## 10.2 E-CENTRAL：灯未熄灭

**玩家决定：**保留中央调度与跨区联络，在现场解除无限续启和危险强制模式，设置受监督的运行边界。

**如何执行：**控制第七塔调度、落实降载与检查，维持跨区调峰，明确临时监督与后续复核责任。

**短期所得：**保留较强的跨区互助与既有运输能力，设备转换成本较低，资源薄弱地区不必立即独自承担全部波动。

**代价与长期问题：**部分地区需要轮流限供，旧系统继续占用维护资源；权力仍集中，退出临时安排、阻止再次取消上限，需要持续监督。不能写成换一个善良领导就永久解决制度风险。

**六个月后的表现：**城市仍有中央调度的灯，公共记录和问责程度由之前选择体现；改造是尚在推进的工作。沃斯的责任不因为方向与她部分一致而消失。

**尾声问题：**谁能确保下一次“临时例外”真的结束？

## 10.3 E-ISLAND：各自的灯

**玩家决定：**有序切断中央强制调度与主要跨区联络，各区域以已准备的本地模式运行。

**如何执行：**按计划隔离联络、使用基础本地装置、转移必要供给与人员，维持地区值守。不是炸毁所有塔，也不是一键关闭所有电源。

**短期所得：**不再由一个中央命令同时强制所有地区超限，地方获得更直接的运行决定权。

**代价与长期问题：**失去跨区调峰和部分互助，某些地区防护范围收缩、需要安置外缘住民；航运成本增加，后续贸易和协作要重新谈判。富裕地区的自主不自动等于贫弱地区的自由。

**六个月后的表现：**出现地方自主管理和新的邻区协定，也出现更明显的区域差异。雾海不会因断联立刻消失。

**尾声问题：**各自拥有决定权之后，谁还愿意共同承担别处的风险？

## 10.4 E-DISTRIBUTED：交换光的人

**玩家决定：**保留有边界的跨区互助，把本地控制、透明的故障隔离和共同协议结合起来。

**如何执行：**六地与中央现场按已验证的顺序切换，使用增强控制、储备和已培训值守，在有限负荷内维持联络；第七塔成为受共同规则约束的枢纽，不再拥有无限强制权限。

**短期所得：**兼顾一定互助与地方控制，技术和数据不再只由一个中心掌握，沿途合作形成实际制度。

**代价与长期问题：**准备与转换成本最高，切换阶段要暂时降低部分服务；维护需要持续共享，响应未必比单一命令更快，设备标准和争议处理会继续消耗人力。小规模与试运行成功不代表以后绝不出现故障。

**六个月后的表现：**部分早期风险指标改善，实际维护与协调仍在进行；庆祝的是人们建立了一种能继续纠错的办法，而不是雾海已经永久被治愈。

**尾声问题：**第一次共同完成切换之后，人们是否还能在平常日子里继续履行承诺？

## 10.5 不标“真结局”，也不假装完全等价

三个方案不必在每个维度完全对称。玩家可以有自己的偏好，也可以认为准备充分时某方案更值得选择。

游戏应呈现真实因果、不同成本与仍待承担的责任，而不是显示善恶分或把某种立场判为正确英语答案。分布式路线可以更有合作重建的希望，但不能隐藏其成本，也不能靠几十个无关收藏品解锁。

## 10.6 结局呈现结构

每个结局由一段即时行动、一个主要政策段落、六个地区结果、四名同伴的相应收束，以及一份档案与问责状态组成。

同伴未招募或其支线未完成时，使用与已知事实兼容的简短近况，不替玩家补写从未发生的和解。每个结局都明确这是六个月后的阶段性结果。

完成基础准备但放弃增强转型，是可理解的选择，不是“失败通关”。玩家后来读回终局前存档完成准备，可以得到另一结局快照，不能回写改变已经观看的结果记录。

# 11. 场景、敌人与制作规模边界（STORY-11）

## 11.1 不让世界观推高美术成本

每个地区使用一个主要视觉主题和若干可复用的设施组件。灯塔共享结构语言，但以所在地、损坏原因、进入方式与任务行为形成区别，不能只换背景颜色。

大事件优先通过前后状态表达：渡船重新开行、矿井停止轰鸣、路牌重新出现、船上收到不同回执。无需为每个分支制作新的城市全景和多人电影镜头。

跨区旅行采用区域地图与少量过渡场景。完整地理、场景数量与布局由第三部分确定，本部分不重复锁死“80—100 张”作为验收指标。

## 11.2 敌人类别的故事用途

| 类别 | 出现理由 | 不允许的简化 |
|---|---|---|
| 雾害生物 | 环境异常、觅食、领地防御或栖息地变化 | 所有生物天生邪恶、全部由最终反派遥控 |
| 失控维护机械 | 错误配置、超负荷、遗留模式与损坏 | 所有机器突然拥有一致恶意 |
| 采掘与试验装置 | 工业设施失控，要求现场处置 | 把机械危险完全替换成读完文章自动消失 |
| 封锁队与受命守卫 | 执行命令、维护秩序或参与滥权 | 所有灯署人员均应被击杀 |
| 少量掠夺者与走私者 | 从失序获利、局部资源争夺 | 每个支线坏人都必须与中央阴谋有联系 |
| 镇潮机组 | 中央危险程序的实体载体 | 在结尾追加无伏笔的邪神或人格反派 |

具体敌人数量、技能和首领阶段由第八部分确定。剧情保留防御、潜入、停机、交涉与战斗的不同方法，但不承诺全流程完全无战斗路线。

## 11.3 动画与声音预算的故事约束

关键动作要能用可交互物件、少量状态切换、简单特效和立绘表达。巨型舰队战、全城坍塌等高成本表现不作为理解主线必需的唯一信息。

关键信息音频必须有可核对脚本与文本替代。可选人物闲聊不要求全部配音；同一主角不会因不同音频预算突然改变口音、年龄或语言水平。

# 12. 生成内容与剧情修改的边界（STORY-12）

## 12.1 哪些内容可扩展

AI 制作辅助可以扩写非关键角色、地区生活、来信、支线变体、维修文件、读听写载体和已有场景的支线状态。生成前提供该地区阶段、允许引用的事实、已知人物状态和禁止改动的事实编号。

无约束实时生成不进入首个可玩样章。固定内容成立后，再由第十一部分评估受控扩展。

## 12.2 必须固定的内容

事故原因、时间线、导师存活、各人的责任、技术边界、谜题唯一条件、结局资格、已执行的承诺不能由生成文本改写。

一封新生成的来信不能授予玩家未取得的终章权限，不能声称另一个地区已经完成实际上没有完成的控制器安装，也不能把暂时未评估的写作夸成已认证的最高能力。

## 12.3 必须经过审校的变体

会引用主线人物、影响有限地区状态或为学习任务提供唯一事实条件的内容，需要检查时间、人物知识、任务可解性和后果。

所有版本保存来源关系。修改英文表达不能偷偷修改条件范围，例如把“只有在备用装置运行时可用”改成“通常可以使用”。

## 12.4 修改程序

变更至少登记原事实编号、变更原因、涉及的章节与证据、受影响的结局和测试。仅修改称呼或对白风格时，也要检查是否影响听力脚本与材料对应。

生成助手获得的制作知识不代表它可以在玩家的当前任务中全部透露。运行时解释只能使用该任务允许访问的材料与揭示层级。

## 14.2 样章的故事截取

第一可玩样章仍以《最后一班渡轮》为核心。它只需要玩家、莉娜、哈文、导师录音，以及必要的工人和船员。

可以用极短前情交代搁浅与封港，再完成取证、工坊行动、修复、书面方案和撤离后果。尾声展示预定断供测试的初步线索，引出下一步调查即可。

不在样章里实现全部世界派系、六塔准备与三种结局，也不靠把整个阴谋提前讲完使样章显得“完整”。样章是一次完整任务体验，不是完整故事的压缩摘要。

本文件可以作为事实、角色和内容边界输入。真正实现前，至少还要读取第三至第六部分的地图、任务、学习和谜题规格，以及第十二部分的技术契约。

允许从本文抽取事实登记、章节节点、人物知识范围、结局资格和待制作材料清单。不要擅自把语义名称固定成最终类名、存档结构或 API，也不要根据缺失字段自行发明语法评分与敌人公式。

实现任务必须注明相关 `STORY-*`、`F*`、`E-*`、`Q-*` 与 `CORE-*` 编号。编号是依赖追踪工具，不是玩家要在游戏里背诵的术语。

# 15. 本版收束与下一步（STORY-15）

本部分确定了一个从个人救援走向共同处置的完整故事：**事故是真实的人为决策与技术风险共同造成；导师有责任但不是万能反派或救星；中央体系有真实价值也有不可回避的问题；改变世界需要证据、设备、人员和承诺，而不仅是揭露一个坏人。**
