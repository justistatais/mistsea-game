## 文档效力与本轮边界

本部分把第七部分的数值和技能转化为有时序、目标、失衡、同伴与首领机制的战斗设计。未特别注明的交互与权限规则为本版基线；生命、伤害、时间、场次和策略权重为待验证初值。本文不是完整可运行游戏，也不声称完整战斗平衡已被证明。

本轮提供：通用战斗契约，18个既定主角主动技能的衔接，6种援助角色的12个基础专属动作，12组同伴变体选择，10种普通敌人角色模板，8个首领方向，工坊/潮门塔/鲁克/镇潮机组的详细流程，44个遭遇槽登记，以及有限参考程序与检查。

其中，44个槽位不等于44个已完成关卡；32个主线路径槽含互斥方法，12个可选槽尚需各自内容。终章完整战斗、地图几何、全装备词条、同伴变体、真实磁盘恢复与人类试玩尚未执行。配套JSON是设计参考，不是最终生产格式。

**英语目标仍然是Academic阅读、听力、写作各6.5；战斗不能提高语言门槛，不能读取英语分数决定伤害、经验或结局。**

# 1. 战斗的职责与边界（COM-01）

战斗提供风险、构筑、资源取舍和行动顺序；探索与解谜继续承担主要内容。玩家不需要先答语法题才能攻击，也不需要开麦、快速打字、盯实时倒计时。

已有基础保持不变：主角3AP，基础攻击2AP、防御1AP，一般现场操作1AP；技能成本沿用第七部分；角色1—30级；新合法遭遇回满生命与专注；同一遭遇内阶段切换不回满；全队共享2次基础急救配发；最多携带2份增强补给；无基础随机未命中和随机暴击；杀敌经验为0。

本部分新增的关键决定：采用**我方阶段→敌方阶段**的整队回合制，先手只决定同阵营内顺序。主角3AP，援助2AP。援助通用普攻系数为0.65A，专属行动使用自己的系数；此前没有确定援助普攻系数，本次明确补齐，不修改主角普攻。详细见CR-COM-008-001。

敌人目标、范围、已知准备和可中断性质在我方选择前公开。英语信息可以说明机关关系和战前路线，但不可把最基础的战斗警告藏在随机掉落文献里。

# 2. 一场战斗从哪里开始（COM-02）

## 2.1 遭遇、尝试与任务不同

- `encounter_definition`：制作内容、场景、敌人、规则与版本。
- `encounter_instance`：当前冒险分支中实际发生的这场处置。
- `attempt`：当前从某个明确战前入口开始的尝试。
- `phase`：同一次尝试中的阶段，不是新遭遇。
- `combat_receipt`：世界接受本次处置结果的回执，不是任务全部完成或英语掌握。

上列是数据语义，不是规定引擎类名。重试不能制造新领奖资格，换阶段不能制造新配发，加载不能暗中变成新遭遇。

## 2.2 正常流程

接近已知风险→查看当前目标和准备→确认进入→冻结队伍/装备/规则版本→显示敌人意图→我方阶段→敌方阶段→回合收尾→再次声明意图。达到胜负或安全处置条件后，先提交结果，再播放可跳过表现。

战前展示主角构筑、两席可用援助、基础配发2次、增强补给2格、敌人可见数量、局部任务目标和安全撤回范围。玩家未带某位剧情同伴时，提供已规定的地方援勤，不默默按单人难度开战。

没有看完全部文献也可以进入。资料在战斗中可暂停查看；读过不等于读懂，查看帮助不改变基本奖励。未发现的剧情秘密不能从战前列表中泄露。

## 2.3 结果类型

本版结果是`controlled`（威胁已制止）、`objective_secured`（满足规定战斗目标）、`defeat`（全队不能继续）或`withdrawn`（撤回本次入口）。界面可写“胜利”，程序仍保存具体结果和目标。

人类降到0表示失去本次作战能力，不自动判定死亡、处决或放走；鲁克的结果固定为制止、解除指挥链并受看管。机械归零表示停用或安全处置。生物的离场表现按遭遇确定，不由英语评分决定。

# 3. 回合、阶段与个人行动（COM-03）

## 3.1 全回合

| 环节 | 规则 |
|---|---|
| 回合开始 | 处理明确到期状态，按当前可见世界快照生成全部敌方意图 |
| 我方阶段 | 按先手降序逐角色行动；主角3AP，援助2AP |
| 敌方阶段 | 按敌方先手降序逐个执行先前声明的一项计划动作 |
| 回合收尾 | 处理回合范围效果、没有受到新压力的压力衰减、待下一回合加入单位 |

双方的先手不互相比较。高敏捷不会获得额外回合、抢占整队阶段或缩短现实思考时间。此项在属性说明中直接写清。先手仍影响谁先制造暴露、先消耗暴露、先架设装置和先进行机关操作。

同先手用持久角色ID排序，不使用译名、网络延迟、动画完成顺序或当前帧率。队列可视，玩家不能随意拖动以绕过先手属性。本版不做“延迟回合后再次提前行动”的系统。

## 3.2 个人计划槽

每名单位每轮最多一个计划槽。倒地者保留逻辑槽位以推进状态时钟，但没有AP。复活不插入新槽。

个人开始：推进计划槽序号→到期效果→普通持续伤害结算→确认是否仍可行动→活着且本轮可行动时回复1专注并分配AP。个人结束：未用AP丢弃→结算个人结束类到期效果。

自然回复不因打开界面发生；角色倒地期间不回复专注，但冷却与到期时钟继续。读档恢复的是原来的个人序号。

技能在个人回合t使用、冷却c，最早可用回合为t+c+1。冷却1在下一次个人回合不可用，再下一次可用。被跳过的计划槽仍推进该时钟。

## 3.3 操作权与援助

默认提供手动指令，也可开启本地的“援助建议”：显示建议动作，玩家确认或修改后执行。它是确定性规则，不依赖联网AI。

可以预先给后面的援助角色下指令，但其出手时必须再次验证目标和费用。目标已倒地或现场变化时停下来澄清，不自动把护盾改为攻击。玩家可以在安全决策边界开启持续自动执行援助，随时暂停，不影响语言记录。

# 4. 站位与目标（COM-04）

## 4.1 小型固定阵位，不做大网格战棋

每侧四个位置：左前、右前、左后、右后。玩家最多3人，敌人同时最多4个可行动主体。战场使用固定站位、少量平移和图标，探索场景不需要变成三维竞技场。

近战可以攻击任何未被同列存活前排保护的敌人。后排同列前排仍活着时，普通近战目标不可选；远程与技术动作不受这一项遮挡。它不是命中率惩罚。倒地前排不再提供保护。

若某一机制目标必须用近战处理，应保证存在移除前排或明确侧路；主线不能要求某一职业独占的攻击类型。

## 4.2 移动

基础换位1AP，每个个人槽最多一次主动换位。只到相邻空位，或与相邻存活且允许移动的友方交换。交换不花接收者AP，也不改变其回合资格。倒地角色的位置保留，不能把尸体拖动作为机制。

H06包含一次同规则换位；已经用过本槽换位、受到普通束缚或没有位置时，仍可按技能说明获得护盾，但不穿墙。泰丝的援护换位也遵守目标移动预算。无借位生成额外AP、无限触发进出区域或多次新回合。

场地操作按明确操作点判断。一般1AP；特殊持续操作必须事先写明。相邻位置和基础工具均有正常进入办法，不依赖高阶外勤工具或指定名字的同伴。

## 4.3 三种攻击锁定

| 锁定类型 | 声明时保存 | 执行规则 |
|---|---|---|
| 人物 | 角色ID | 追踪该人；移动不能自动闪避。目标已失去作战资格则取消，不偷偷转打最弱者 |
| 位置/列 | 指定位置集合 | 结算当前仍在这些位置的合法单位；移动可以规避 |
| 全场 | 四个战场位置 | 结算当前全部站立友方；不能移到声明时空着的位置躲掉“全场” |

有特殊后备目标规则时，必须在意图中声明；第一版默认取消，不使用隐藏随机改目标。无合法目标而取消的动作不触发攻击开始类装置。

# 5. 敌人意图必须可信（COM-05）

每张意图显示动作、目标类型、目标/范围、基准伤害、当前防护下的预计影响、是否可被完整取消，以及附带的普通状态或召唤条件。显示的血量损失可因玩家刚施加护盾而变化；这不代表敌人改了计划。

敌人的基本动作家族为：普通攻击、列攻击、全场攻击、准备、防护、有限增援、局部控制。普通单位每轮只执行一个声明动作；一段多次视觉挥击仍可属于一个根动作。

蓄力重击提前显示。本版不在动画最后突然换目标，不根据玩家选择防御而临时改成另一种攻击，也不凭隐藏英语答题正确率改变敌人策略。

增援必须显示来源、数量和次数。默认同一信号兵每遭遇至多一次，不能无限产出敌人。新单位最早下一轮行动；它加入前要显示下一轮的意图。总实体上限仍为4，召唤位不足时延期或转入已声明的替代行为，不覆盖现有单位。

发生首领阶段变化时，旧阶段尚未执行的危险意图由明确的无伤害“重校准/整队”替换，新阶段的伤害意图在下一轮发布。不追加一个从未预告的插队攻击。该保护不重填玩家资源。

# 6. 动作验证与结算顺序（COM-06）

统一处理动作，不能每个技能自行写一套伤害和奖励脚本。

1. 验证当前人物、回合、AP、专注、冷却、槽位、目标、作用范围、内容版本与输入上下文；无效请求不先扣费。
2. 玩家确认仍对应当前状态后，一次记录费用、冷却、次数和动作身份。
3. 敌方有效攻击将要开始时，按稳定顺序触发合法拦截装置；派生装置攻击不再次触发攻击开始链。
4. 重新核对执行者是否还可行动，是否因失衡取消。已经支付的动作按明示规则消耗，不能获得额外AP退款。
5. 取动作快照；同一动作对同一目标的多段系数先合并，处理加成、暴露和防护，最后取整一次。
6. 先吸收护盾，再扣生命/停止进度；再结算压力、后置暴露与受控触发。
7. 处理倒地、普通状态、阶段边界与当前完整动作的胜负。不要在一个群体动作的中途提前发胜利奖励。
8. 提交稳定动作结果，之后播放可跳过表现并允许保存。

预测界面是只读的；查看“预计伤害”不消耗暴露，不花专注，不推动机关。相同指令重复到达返回原结果；同一指令ID携带不同参数拒绝。

## 6.1 伤害式

沿用第七部分：输出A或T×动作系数×(1+通用加成，最高50%)×(1+已成立暴露加成，最高40%)×(1−装备减伤，最高45%)×(1−本次适用临时减伤中的最大值，最高35%)，最后向下取整。

没有任何来源的失衡压力不凭空出现。主角基础普攻为1.00A，锤为0.90A；援助通用普攻再乘0.65，援助专属技能使用各自系数。技能写A时沿当前武器类型，写T时固定技术。

机制锁护是单独的合法性/进度门，不混入普通45%减伤上限。锁护时清楚显示伤害为0；不能靠满破甲绕开必须的安全操作。当前主线不引入另一套随机元素抗性、幸运暴击、闪避率和反射循环。

M10及其他“压低敌人首次攻击”以该次伤害适用的临时保护来源处理，与已有防御取最大，不再加一个独立乘区。

## 6.2 暴露

一次充能，不叠加。H01在本击之后施加，不能追溯增强本击。再次施加只续期/保留一充能。默认到施加轮之后的下一完整轮结束为止，或被下一次有效伤害动作使用。

实际加成由使用者的感知和已明示被动计算。伤害被普通护盾全部吸收，仍算有效伤害动作并消耗暴露；目标非法或机制锁护导致完全无效，不消耗。多段同根动作只消费一次，群体动作对每个目标单独判断。

装置是可消费暴露的派生伤害动作，但不触发“本人下一次主动伤害动作”的主动增益；同一次来源不得通过派生事件递归获利。

# 7. 失衡与恢复保护（COM-07）

敌人显示稳定条。普通阈值初值3、精英5、首领8，个别明确配置可不同，工坊为4。当前带压主角动作是单目标；未来多目标压力需要另行声明总量和分配，不自动向所有目标复制六点。

压力沿用公式：将本动作合法基础压力合并，乘(1+0.02×[力量−5])后向下取整，每动作最多6。防具和生命盾不自动免疫压力；机制锁护或稳定恢复保护会拒绝新的压力并明确显示。

| 达到阈值时 | 后果 |
|---|---|
| 普通/精英 | 取消下一次计划动作，授予一次普通暴露，压力归零 |
| 首领 | 不跳过整体行动；下一次攻击最多按35%临时保护减弱，并取消该动作明示可中断的附带效果；授予一次暴露 |

之后进入恢复保护。被取消/被削弱的那次槽不解除保护；还要完成一次未被失衡取消的计划槽，才可重新累积压力。无目标而落空的槽视为已消耗的计划机会，不秘密改目标。保护期间装置仍可以伤害，但压力显示“恢复中，不累积”。

整轮没有接受任何有效压力、且不在恢复保护中时，轮末压力−1，最低0。不能通过不断切界面清空或增长条。

首领失衡不是“全部机关作废”或“阶段自动结束”。本版不对玩家叠加可连续剥夺整轮的眩晕链；玩家的普通负面状态保留攻击、防御或澄清操作的出路。

# 8. 护盾、普通状态与时钟（COM-08）

护盾沿用max(旧剩余,新值)，并受目标最大生命50%上限约束；不算术相加。护盾强度加成同池最高50%。无特殊说明时到来源第二个后续计划槽开始过期；来源倒地也推进时钟。

重新施盾可按既定规则把盾池期限延到较晚期限，较弱盾不覆盖强盾。临时减伤不是这样：每个来源独立保存值与期限，当前取最大。10%长效果不能替已过期的30%效果续命。

实际引擎期限应绑定稳定来源计划槽/阶段边界，而不是渲染帧或可能重排的数组下标。死亡留下逻辑时钟；增援不能让旧状态延长一回合。

| 状态 | 默认有效范围 | 清除/规则 |
|---|---|---|
| 基础防御 | 到本人下一计划槽开始 | 不叠同名，每个本人槽最多一次 |
| 下一击增强 | 一次主动伤害动作，且有来源期限 | 群体动作按根动作使用一次，装置不额外吃主动增益 |
| 暴露 | 下一次有效伤害动作或下轮结束 | 不堆充能 |
| 普通蚀伤 | 接下来两个目标计划槽开始各结算一次固定值 | 按普通防护和盾处理，不再触发暴露/反击；可净化 |
| 普通束缚 | 到施加后规定目标槽结束 | 限制换位，不封锁全部技能、物品和阅读 |
| 普通虚弱 | 目标下一次攻击或规定期限 | 等价于15%本次临时保护，不独立无限乘 |
| 机关锁护/任务封锁 | 按现场动作和配置变化 | 不是普通负面状态，净化无效 |

普通蚀伤的原始数值由遭遇明确给出，不靠现实时间滴血。源系数固定记录，防御按结算时真实状态；不在后台阅读时消耗生命。普通驱散只作用于声明的普通状态，不解除历史责任、气象雾害或中央联锁。

# 9. 装置与派生事件（COM-09）

默认每施放者1件，M08或奥伦规定变体可到2件。部署绑定具体敌人、支付、序号、来源与当前遭遇。一个敌方攻击开始，最多触发同一来源的一件，按创建序号决定；不同来源可以各触发一件，但敌人死亡或普通失衡取消后结束该攻击链。

敌人已经因失衡跳过、没有合法目标、只是架盾/准备，都不触发“开始攻击”装置。目标/来源退场后清理挂载，不自动转绑另一个目标。

回收1AP，仅对本人未触发的真实装置成立；M09只返还明确一次，并服从每个人槽1点、每遭遇2点的合并返还上限。返还触发、护盾派生、M12及护甲被动都有独立稳定身份和预算，不能从护盾再触发自身形成循环。

配置在遭遇入口冻结。战中请求调整时明确返回当前入口、用新配置重建同一次工作尝试；保留草稿和已取得材料，恢复战前资源，不保留本次局部伤害成果。不能把不同难度下的资源与结果拼接。

首版不自动根据连胜涨怪物，不按阅读速度触发辅助。失败后可以建议查看意图、换装或调整战斗模式，但不替玩家偷偷改变设置。

# 20. 撤回、保存与反刷（COM-20）

任何合法我方决策点提供“撤回本次战前入口”。它是放弃本次尝试并恢复入口，不是携带已经击败半数敌人的收益免费逃跑。文本和已取得资料按既有学习规则保留；本次战斗局部机关/伤害按入口恢复。开始前已经提交的永久探索进展不被抹掉。

多阶段首领默认以完整遭遇入口重试，不把阶段点同时作为回满补给点。可以随时在稳定动作边界存档，以便分多次游玩，读档继续则保留原消耗。

快照至少包含版本、遭遇实例、尝试、难度、入口资源、当前轮/计划槽、HP/盾/专注/AP、状态期限、冷却、次数、装置实例、锁定意图、阵位、机关版本、待加入单位、动作回执和结果状态。学习材料/草稿另行持久化，不依赖角色是否站立。

动画不是权威。如果结果已提交，恢复后补播/跳过表现，不能重扣物品重发奖；结果尚未提交，恢复上一完整状态。结算台账跟随冒险分支，不用全局学习档案禁止旧分支合法重试，也不把新attempt当新奖励。

战斗仅发送“哪一威胁已制止、哪些局部目标已满足、用了什么实际物品”的受控结果。第四部分统一应用世界后果和奖励；没有战斗杀敌奖励再叠主线完成奖励。

# 21. UI、声音与低成本表现（COM-21）

主界面显示本轮队列、角色3/2AP与专注、敌方意图、稳定条、当前护盾及普通状态。目标预览区区分“原始伤害”“当前防护后损失”“机制锁护”。暴露和稳定恢复都用图标+文字，不只靠颜色。

默认当前主角四主动+基础动作，援助两专属+基础动作。长说明按需展开，资料面板继续使用第十部分共用工作区。不把技能说明压成密集英文缩写要求快速读。

敌人可使用固定图、两到三种姿态、短位移、闪白和音效；特殊机关用状态层变化。摄像机震动、闪烁、动画速度和声音可调。动画加速不能改变模拟时钟，跳过不能跳过结算。

全程可键盘完成，焦点位置稳定。确认重要行动前显示目标；退出写作不把回车重新解释成技能确认。音频装饰不得盖过作为线索的语音。

# 25. 与后续章节的连接

第九部分确定招募、人物关系、阵营、私人支线、援助建议的性格表现；不根据好感重写战斗公式或隐藏必需证据。第十部分完成布局、可访问性、输入焦点和学习工作区。第十一部分完成素材/文本/音频的受控生产；第十二部分统一引擎、数据、事务和发布格式；第十三部分形成跨模块Codex任务图。

本版仍有明确待验证项：长战过长，混合构筑在长战中余量偏低，纯防护主动栏需要更好的本地建议策略，终章28级零稀有配置尚未模拟，完整站位与援助变体可能改变现有数值。不能用增加英语门槛或要求所有玩家洗成同一流派解决这些问题。

## 最终原则

**让玩家看见威胁并作出可执行回应；让构筑改变方法，而不是决定能否取得主线知识；让失败可以重试；让阶段、资源、人物与世界结果分别记账；保持雅思6.5语言目标，不把阅读速度当作战斗操作能力。**
