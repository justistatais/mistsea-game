# NPC-MAT-04：查验申请不等于公开许可
类型：受控审阅说明与对话。目标：IELTS Academic 6.5；未校准，未配音。
场景：R4-S04；CQ-MIRA-02。局部证人使用W-04代号；不承载主线唯一证据。

## Review request
The reviewer needs to confirm when the record was received, which role the witness held, and whether the copy matches the original. A home address is not required for this review. The permission already given applies to one named reviewer and to this purpose only. It does not permit publication on the notice board or forwarding to a wider group.

## Dialogue
**Mira:** We can send the relevant fields without pretending that the rest of the record has disappeared.

**June:** Keep the original in controlled storage. The reviewer can receive the comparison sheet and a record of how it was prepared.

**Player:** What happens if the reviewer asks for more information later?

**Mira:** We check the new request. If it needs a different permission, we ask for that permission before sending anything. We should not describe the first agreement as consent to every future use.

**June:** And if a copy has already been delivered, changing the permission does not make the recipient forget it. We can restrict future sharing and record the correction, but we must be honest about what has happened.
