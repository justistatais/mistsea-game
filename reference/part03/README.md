# 第三部分设计包 v0.1

本包是地图、探索与关卡结构的设计交付，不是已经实现的游戏，也不是最终运行时数据格式。

## 文件

`Exploration_Level_Design_v0.1.md`：正文，含全区连接、78空间登记、六场景样板和32项后续验收。

`Exploration_Layout_Reference_v0.1.json`：设计登记与六场景灰盒坐标。门禁使用语义说明，不能直接作为脚本求值。其余场景没有完整碰撞几何。

`Exploration_Validation_v0.1.md`：当前静态检查与有限状态模型结果，以及未验证边界。

`dependencies/`：第一、二部分的原版引用副本，未在本轮修改。

`validation/validate_reference.py`：只用于复核登记、简化导航与抽象状态；不是游戏代码。使用Python 3标准库。在本包根目录运行：

```sh
python validation/validate_reference.py
```

运行会重写本包的静态核查记录和validation目录中的检查摘要，不修改世界设定、场景参考或任何用户的游戏存档。模型未包含实际引擎碰撞、存档事务、写作评价、真实战斗经济或玩家测试。

## 使用顺序

先读前两份依赖，再读第三部分正文；把配套JSON作为ID与空间参考；第四部分之后逐项完善任务依赖。引擎和正式结构由第十二部分统一，Codex开发任务由第十三部分整合。

不要根据本包自行补全尚未决定的学习算法、角色数值、结局条件或运行时AI权限。
