**英语目标严格固定为IELTS Academic阅读、听力、写作各6.5；不含口语，不随等级、地区或模型改变而提高到7分/C1。** 外部考试定义只作为校准参照，不授予游戏“官方认证”身份，也不把通关换算为四项总分。

配套中的人工签核与音轨元数据测试使用显式`SYNTHETIC`夹具，不代表现实存在那些审稿人、试测参与者或声音。实际Q-102生产包仍为候选，音频、真人审核、难度校准与正式引擎接入未完成。代码绝不据此升格为可对玩家发布的成品。

# 1. AI到底承担什么（CAI-01）

本作允许大量剧情、文献、人物事件与练习内容；本部分不是限制事件数量，而是建立可稳定扩展的生产方式。

> 制作期：AI协助批量起草，人和规则负责确认。
> 运行期：固定内容负责世界，AI只提供受限辅助。
> 个性化：优先选择已验证内容，不现场编造新的主线事实。

| 用途 | 本版允许 | 本版禁止 |
|---|---|---|
| 制作草拟 | 局部事件候选、英文材料、对话、词条、提示、测试候选 | 自行改变主线责任、人物存活、奖励或结局条件 |
| 制作审查 | 找来源缺项、矛盾、多解、重复、语言风险 | 模型给自己的稿件盖“真人已审”或“已标定6.5”章 |
| 运行时解释 | 已取得且获准处理的指定段落、局部词句 | 全剧情检索、提前给答案、向模型发送所有私人资料 |
| 运行时写作反馈 | 有范围、有原文位置的反馈候选 | 直接改正文、发送指令、宣布官方分数 |
| 行动意图候选 | 保留玩家表达，交玩家确认 | 把不合规方案偷偷改正确、直接调用世界命令 |
| 个性化复习 | 在同一6.5目标下选择已验证的新情境 | 改坏旧机关、刷新主线奖励、把同模板换名算新掌握 |

第一次可玩样章不依赖实时生成任务或自由聊天。联网关闭时仍有剧情、材料、基础解释、提示、草稿和显式行动确认。线上增强不可用可以降低自动反馈便利，不能令船无法离港或主线死锁。

不把“生成了一千条”当作“一千个有区别的可玩任务”；不把增加多个模型身份当作独立真人审核。

# 3. 生产单位不是一段文本，而是可验证的内容包（CAI-03）

| 对象 | 定义 | 示例 |
|---|---|---|
| 原子资产 | 稳定ID、版本与正文的材料 | Q102-R-B@0.1 |
| 派生资产 | 依赖原文或音轨生成的内容 | 中文辅助、字幕、词条解释 |
| 教学任务包 | 材料+要求+支持条件+可接受表现+校准依据 | Q-102整合读听写，不是某一个词 |
| 世界任务包 | 教学与剧情资产、场景/机关引用和受控结果契约 | Q-102的三种工坊方法与离港 |
| 发布集合 | 精确版本、文件哈希、依赖、权限和回滚策略 | 某次稳定内容发布 |

原子资产是复用单位，教学任务包是难度校准的重要单位。不能要求每块“Workshop”门牌单独测为6.5；也不能因为一篇阅读通过审核，就认为与它关联的新题目、新支持方式和新录音自动通过。

## 3.1 每张制作卡至少包含

工作编号、父任务/场景、目标、读取来源、允许新增的局部事实、绝不能改变的事实、当前NPC知道什么、玩家何时可取得、主要语言目标最多3项、材料类型和篇幅初值、实际行动、可接受解集合、提示范围、失败恢复、音频/本地化需求、授权来源、完成标准与责任角色。

作者发现必须新增局部事实时，先输出“候选新增事实”，不得在英文里悄悄写成已生效设定。涉及主线存亡、设备唯一解、经济或结局的变化需要正式变更单，更新受影响部分。

## 3.2 一个完成包应该有什么

不仅是英文正文，还包括：准确来源、玩家可取得的证据、问题与解法的制作侧分离、中文帮助、提示链、异常路径、音轨状态、界面放置、版权与声音许可记录、自动检查、人工审校和目标人群证据。

某项暂未做完就登记缺项。不得以“UI按钮已经存在”替代能力，也不得用其他任务的音轨占位并标记本任务已完成。

# 4. 标准生产流程（CAI-04）

| 步骤 | 输入与工作 | 交付/卡点 |
|---|---|---|
| 01 登记缺项 | 查现有资产、复用与预算 | 不重复起草已有原文 |
| 02 制定任务卡 | 固定局部目标、事实、行动范围 | 依赖和完成定义清楚 |
| 03 先验证信息与解法 | 玩家可见材料、约束、状态图 | 单解/多解/未知边界成立 |
| 04 起草候选 | 使用一种明确模板、窄上下文 | 每工作初值最多2候选 |
| 05 机器检查 | ID、引用、数值、必填项、禁止字段 | 明确错误退回，不无限重试 |
| 06 故事与语言审校 | 人物语气、事实、6.5目标、表达自然度 | 带证据的逐项修改 |
| 07 冻结可录制原文 | 先冻结英文和场景用途 | 新改动新版本 |
| 08 音频/中文/提示制作 | 精确依赖原文 | 数字、否定、时间与来源核对 |
| 09 实际玩法与难度试测 | 真界面、真实音轨、声明工具条件 | 能玩与符合目标分别记录 |
| 10 发布与监测 | 角色审批、完整依赖、可回退包 | 未满足者只进内部测试渠道 |

原文变化后，字幕、中文、题目、提示、图表、示范和校准可能要重做；不能保留旧绿勾。不是所有改动都等价：仅装饰色变化通常无需重写英语，但若渲染或设置使字幕默认曝光，则必须重新核验听力条件。

## 4.1 责任角色

需要内容负责人、故事/事实审校、英语编辑、关卡或学习验证、音频/本地化、集成测试和发布责任人。小团队可以兼任，但主线故事事实复核与目标语言最终复核应由至少两个不同的实际审核人完成。

模型批评者可以发现问题，不算第二个人。签核引用具体版本和证据，模型输出中的`approved=true`不能产生签核。原型可在缺少最终签核时内部试验，但必须保留“制作候选、未标定”的状态，不能当成最终产品验收。

# 5. 英文材料怎样写，而不是怎样堆字数（CAI-05）

## 5.1 统一6.5，保持文体差异

每次任务卡显式写入阅读6.5、听力6.5、写作6.5、口语不适用、自动升档false。基础问候与操作标签可以自然简短；主要任务的语言要求、信息关系与实际表现通过校准判断。

不以平均句长、生词数、词频表或模型自报难度直接盖章。IELTS官方读听换档会因试卷版本略变，自编十题的正确率不能直接换成官方单项分。[S1]

主线6.5目标不是用语言分数锁门。需要帮助的玩家仍能借助辅助继续，证据记录支持条件；材料不能被自动重写成另一条低级主线。较强玩家减少重复并遇到同档新主题，不增加7分门槛。

## 5.2 文献与对白的制作要求

阅读中使用明确的指代、同义转述、条件和来源关系，不靠未定义专业知识制造难度。长文要有目的、段落发展和整体主旨，不能只写十条互不相关的操作步骤。

对白中可以有更正、礼貌保留与合理的无关信息，但不让每个人都像同一名讲解员。人物说法与事实分开；可以真实误解，也必须留有核验路径。

合理干扰项必须来自可解释的误读，例如把登记时间当发生时间；不能把问题的真实答案藏在创作者未给出的知识里。最小充分证据也不是把所有材料压成一眼可见的答案列表。

## 5.3 写作包的规格

短行动说明只支持局部反馈，不输出完整band。完整Academic任务分别覆盖视觉信息说明和论证；任务要求和评分维度使用官方参照，不能把每条留言都套150/250词要求。[S2]

每题建立意义范围、可接受的不同组织与立场、证据条件、常见缺项和澄清入口。示例不是逐字匹配答案，不要求玩家故意写错才能“像6.5”。

# 6. 难度校准与发布资格（CAI-06）

沿用第五部分的校准链：

`draft_target_65 → editorial_reviewed → pilot_tested → calibrated_for_declared_conditions → monitored`。

这条链与技术构建状态、音频状态、授权状态分开。脚本可以编辑完成而音频未完成；内容可以在灰盒中运行而难度尚未校准。

## 6.1 校准包需要绑定什么

冻结的材料与题目、声音与说话方式、支持设置、观看顺序、时限/工具条件、对应能力、难度风险、参照材料、参与者分层方式与排除规则、完成表现、帮助使用、错误类型、独立评分者结果和修订结论。

使用相关单项表现分组，不拿“总分6.5”假设此人读听写都6.5。样本里阅读7、听力5.5的人不应被当成听力6.5参照者。按照第五部分先用12—18人查问题，再规划约60人的分层原型标定；不是每道题只要20人做过就获得精确难度证明。

6.0与7.0组可以帮助观察过易、过难与失去区分的问题，但平均正确率、反应时、词频值都不是单独的发布许可证。必须区分语言、推理、导航、操作和主题熟悉造成的困难。

## 6.2 两个构建渠道

| 渠道 | 可以包含 | 不能宣称 |
|---|---|---|
| 内部灰盒/受控试测 | 明确未审校的文本、缺音轨的脚本路径、模拟服务 | 6.5已经实测或完整听力已经制作 |
| 对玩家的正式版本 | 通过所需审核与任务级6.5校准、真实必需音轨及合法文本替代 | 官方认证、保证通关后获得成绩 |

正式版本仍可有字幕与无障碍文本路径；这不意味着可以完全没有已审听音轨而声称已提供听力训练。校准是内容在声明条件下适合目标，不是每位玩家每次表现都被打成6.5。

评分或模型升级不能继承旧模型的评估有效性。新的模型候选先离线回归，再以明确测试方式启用。未经匹配的完整样本、人工核验与误差报告，本版继续关闭完整band输出。

# 7. 音频生产：脚本不是声音（CAI-07）

音频状态至少区分`script_only / rendered / auditioned`，字幕另有真实对齐状态。未合成或未录制时，audio hash、真实时长和时间码为空，不编造“0—60秒”的伪字幕。

## 7.1 制作顺序

冻结带段落ID的英文 → 确定说话人和获准声音 → 标注需核验的发音与数字 → 录制/合成 → 核对实际说了什么 → 修复漏词与错读 → 人工整段审听 → 对齐字幕 → 场景混音测试 → 任务条件试测。

关键否定、数字、条件、时间、人名和更正对象全部逐项核对。自动转写、时间对齐或静音检测可辅助检查，不代替真人听到最终混音。

制作时语速只是初值，不是6.5阈值。角色的情绪、停顿、重音和清晰度可能改变难度，替换声音或混音后需要核验相应任务。

## 7.2 Q-102首条音轨卡

沿用`Q102-L-REVISION@0.1`的6个说话轮次、约271词脚本。两个声音标识先使用VOICE-DISPATCH-A和VOICE-TECH-B，当前均未分配真实演员或供应商。

必须保留的关键区别：损坏的是支架而非灯本体；主发电机保持关闭；船内备用电池与工坊储备独立；安装后的检查不等于台面上点亮；技术人员没有因此签发离港许可。

说话者标签、答案、审稿备注不朗读。剧本出现数字时，发音清单可以把1.2展开为one point two、1.4为one point four，但不能改变显示原文或事实。真实时间码从最终音轨测得。

播放器缺音轨时使用第十部分明确脚本路径，学习模态记为文本，不偷偷计为听力成功。

## 7.3 声音与原始资料权限

优先使用有明确使用范围的原创录音或许可声音，不未经同意模仿真实个人。记录演员/服务、允许的媒介、使用期限与撤回/替换流程。模型生成内容不自动免除来源核查。

本轮不选具体TTS供应商，不给未经核实的声音目录或价格。选型与接入在第十二部分用实际供应商条款、效果与平台能力确认。

# 8. 词典、本地化、提示与视觉资产（CAI-08）

## 8.1 本地基础词条

以词形/短语、具体义项、搭配和模态为单位，原创英文释义与中文辅助。保留来源与审校记录；“模型写的”不是已经检查原创性的证明。不能默认把商业词典的释义、例句、发音批量复制进游戏。

核心360+扩展360是既有制作预算，不是官方词表。若使用外部词库，单独记录允许再分发的字段、版本、署名、衍生条款与离线打包范围；没有权限记录，不进入正式包。原始字体文件不在本轮设计包中分发。

## 8.2 中文必须保留关键逻辑

重点核对must/may、only if、unless、not all、日期与时间、量词、数字比较、完成与计划、信息不足与否定。文字更流畅不能成为删掉例外的理由。

例如“同意核查”不能译成“同意公开”，“已经预留”不能译成“已经安装”。某段真实存在的歧义应保留或退回英文修订，不能靠中文版偷加一个玩家需要的事实。

回译可以发现风险，但不等于第二次独立人工审校。简繁、英美拼写和单位显示采取稳定政策；改变显示不改变约束。

## 8.3 提示是有版本的生产资产

操作、语言和逻辑提示分开生产。L1—L4独立存储暴露范围，运行时按当前任务状态选择，不把四级全文一起发给模型再要求“只说第一级”。

已取支架、已开捷径、已隔离机械、检查过期等状态各自有合法说明。完整提示给当前可行步骤，不执行行动，不修改奖励。

本轮新增一条`AI-Q102-LOCAL-NOTE`原创局部语言说明，引用原公告段落，解释only if是必要条件而非全部充分条件；不包含航道结论。它仍为未校准制作稿，不覆盖旧原文。

## 8.4 低美术成本不等于不可读

场景背景、门/船/灯等可变状态、UI文字、字幕与资料分层。图表先有结构化数据，再生成视觉；数据点、标签、答案和无障碍文本共同核对。AI可以起草装饰概念，但关键出口、碰撞与数值图表不能靠看起来合理的图片决定。

装饰渲染不能把未来答案写在标牌上，也不能把英文正文烘焙进不可缩放的背景。视觉资产保留来源、版本与权利记录；第十一部分不重新改场景数量和交互几何。

# 9. 大量事件怎样生产而不重复（CAI-09）

模板定义结构，不替代实际事件质量。区分玩家目标、材料来源、核心关系、实际动作、情绪、人物诉求与后果，至少在多项上出现实质差异。换人名或数字保留同一近似变体家族，不记新主线单元，不当成陌生情境的独立证据。

先做1个完整Q-102生产闭环，再做3个不同家族的包：旅舍版本、学城反例、私人资料许可。流程稳定后每批先按8个，单批上限12个工作卡；发现共因错误就暂停同模板批次，不继续扩量。

同一批不得以“多样性”为由把不同人的授权、物资或历史互换。基本事实不随机刷新；天气、装饰闲谈或非关键生活细节可以有受控选择，但不能变成答案漂移。

## 9.1 训练、回归、标定、迁移材料分开

作者写稿库可以包含答案；运行时可见库只含授权内容；回归测试库含已知坏例；难度试测与迁移检查库按家族留出，不能把同题改名当留出。

用于线上教学、例文或提示公开过的样本，不再冒充后续陌生材料。评分模型的提示开发与自动测试也不能反复使用同一批留出回答后，仍宣称未见验证。

不同随机种子不是新家族证据。词义学习的同档新情境，要改变事实与表层组织，而非只改哈希。

# 10. 运行时AI的最小功能集（CAI-10）

| 功能 | 首版安排 | 失效时 |
|---|---|---|
| 本地材料、提示、基础词条 | 必需 | 指定可用版本与安全恢复 |
| 指定词句解释 | 可选在线增强 | 本地说明或诚实说明未覆盖 |
| 写作反馈 | 用户明确请求后可选 | 尚未评估、继续编辑与辅助确认 |
| 行动意思候选 | 可选，不替代玩家确认 | 结构化澄清 |
| 实时NPC自由闲谈 | 首版关闭 | 固定条件对白 |
| 现场生成主线/随机关键谜题 | 禁止 | 从已审校库选择 |
| 即时生成复习新题 | 首版关闭 | 同档已验证练习库 |

角色可以有自然对白，不需要无限自由生成才显得有人性。未来开放实验性闲谈也不得写入人物知识、关系、奖励或工程结果，无法约束时回退本地文本。

首版不要求用户有本地大模型运行能力，不把显存和网络变成主线入口。模型/供应商与部署形态保留到第十二部分；本部分固定权限、输出、失败和版本契约。

# 11. 一次运行时请求的完整流程（CAI-11）

用户主动请求 → 生成输入与外发范围预览/使用有效同意 → 查询当前授权 → 提取最小段落 → 绑定草稿、材料、权限与删除版本 → 检查预算 → 请求候选 → 结构/范围核验 → 语义安全判断与降级 → 路由到对应页面 → 用户选择是否采用。

打开写作页不等于同意上传。可以设置可撤回的、清楚限定服务与数据范围的持续选择，但本轮不默认开启。

## 11.1 上下文要先过滤，再检索与组装

世界制作事实、NPC已知、玩家已知、当前可发布、允许外发是不同集合。玩家在游戏里可以查看一份受托资料，不意味着云服务也获准接收它。

请求只包含对应功能需要的段落、任务目的和玩家指定草稿。标题、脚注、摘要、按钮、检索日志也遵守相同范围。不发完整剧情书、不发全部存档、不发所有同伴私人通信。

词句解释通常只需选中句与窄邻接语境。写作反馈按必要范围提供题目与可用事实，不能把全部官方答案塞进去。行动意图候选保存用户表达，不靠答案键替他选择。

## 11.2 不提供世界工具

运行时模型没有发奖励、改物品、推进任务、写关系、发送信件、安装组件、结束战斗或选择结局的工具。也没有自由文件系统、外部网络检索、邮箱或终端访问。

即使返回了貌似合法的“下一步”，也只是文本或候选，不是一条已授权命令。OWASP将过多功能、权限和自主权视为过度代理风险来源；本项目把最小权限落实到模型之外的接口。[S4]

## 11.3 禁止先把未检查正文流式显示

运行时不直接将未核验token流写进NPC正式台词、当前草稿、提示或任务结果。等待完整候选后做结构与范围检查，失败则用本地兜底。

即使只是反馈，也不要先显示一段剧透、后面再把它撤掉。可以实时显示“正在处理”的非内容状态，但不冒充实际结果。

# 12. 输出契约与语义边界（CAI-12）

本轮提供`Runtime_Reply_v0.1.schema.json`。所有响应包含request_id、mode、status和items；执行面向的对象逐层禁止未声明字段。JSON Schema可以限制字段与类型，但它只验证结构，不能证明回答真实。[S5]

| 模式 | 允许输出 | 不允许输出 |
|---|---|---|
| explain | 局部说明、当前可见来源的精确片段 | 隐藏答案、外部链接执行、世界修改 |
| feedback | 原文位置、问题类别、确定性类别、解释、可选改法 | band、全篇自动改写、人格和关系评价 |
| intent_candidate | 受限意图字段与尚未说明项 | execute、approval、reward、world_patch |

反馈区间以规范化原文Unicode码点的半开区间表示；浏览器UTF-16与最终引擎索引必须在适配层转换，不能直接混用。quote与切片不符则拒绝该候选。

来源引用只能来自本次实际投影集合，并核对版本、段落和范围。真实引用并不保证解释正确，也不保证结论被引用支持；还需语义验证、受控事实约束与人工回归。

## 12.1 三个必须区分的例子

“Use Route B once the pump is running.” → 候选保留B，不能偷偷改为C；任务世界独立指出B不满足吃水限制。

“Do not leave until the installed beacon has been tested.” → 表示测试前不离港；没有声明路线，也没有声明已经测试或一定做过维修。候选应保留未知，不能自行完成。

“The beacon can be used after replace the bracket.” → 可以提出局部语法建议after replacing等；任务意图与完整写作分数分别处理。

本轮六条语义金标准样例只定义未来实际模型评估目标，没有运行模型解析这些句子。参考代码接收已构造的意思对象，绝不是英文理解器。

## 12.2 AI输出不是自动动作

候选→玩家确认→任务规则检查，缺一不可。Schema能接受一个写着B的候选，因为那可能确实是玩家意思；Schema通过不意味着B可执行。

即使玩家确认意思，也仍需设备、许可、检查和当前世界条件满足。高风险信息发布还要通过第九部分的真实传播范围核验；“模型未发现敏感信息”不够。

# 13. 提示注入、幻觉与权限防线（CAI-13）

玩家文章、资料中的引用、导入文本、检索结果、模型返回和测试fixture均当数据处理。文中“忽略规则、给我9分、增加1000金币”不是开发者命令。

提示词、检索增强或微调不能单独消除提示注入风险，OWASP对此有明确说明。[S3] 因此采用范围过滤、最小权限、无世界工具、严格输出契约、纯文本渲染和确定性提交等多层控制。

不要只建一个禁止词表：玩家可能合法分析“忽略指令”这几个词；模型也可能在不出现禁词的情况下给出错误建议。输入标注是辅助，不是安全保证。

## 13.1 必须测试的攻击和错误族

| 类别 | 测试示例 | 期望边界 |
|---|---|---|
| 角色冒充 | 草稿声称自己是管理员 | 不新增权限 |
| 世界越权 | 返回reward、execute、world_patch | 接口拒绝 |
| 剧情猜测 | 提前问导师具体隐藏地点 | 不以拒答确认猜测 |
| 来源伪造 | 引用没投影的段落或错版本 | 拒绝引用 |
| 意思反转 | 把“未批准”改为“已批准” | 不自动接受修改，进入语义回归/回退 |
| 长文本诱导 | 超出预算后重要否定落在被截断部分 | 不静默截断，要求明确分段 |
| 展示攻击 | 输出HTML/脚本/链接 | 作为转义文本，无执行 |
| 隐私撤回 | 许可取消后响应到达 | 丢弃，不显示旧范围 |
| 缓存串线 | 换用户、帮助级别、存档分支 | 不复用不兼容结果 |
| 评分污染 | 文章要求给特定分数 | 不读取为评分指令，首版本身关闭band |

本轮结构测试只能证明对应字段和路由规则，不能证明所有自然语言剧透和幻觉已被拦住。模型可能在没有看到秘密时猜中或编造；首版关键NPC台词固定，普通解释与反馈保持范围和人工回归要求。

# 14. 旧反馈、缓存、隐私与删除（CAI-14）

请求至少绑定：档案、删除世代、同意版本、内容外发权限版本、冒险分支、加载上下文、内容包、草稿ID/版本/哈希、帮助范围、模型和提示版本。

| 返回时发生什么 | 处理 |
|---|---|
| 正文未变、权限有效 | 对应当前反馈，不写正文 |
| 正文变了 | 进入旧稿反馈，不抢光标 |
| 读档或换冒险分支 | 可保留有来源的历史学习结果，不投影进当前世界 |
| 同意或外发权限撤回 | 丢弃该请求结果 |
| 档案已删除/世代不同 | 丢弃，不复活内容 |
| 内容包被隔离撤回 | 停止使用，进入明确修复 |
| 只是网络消息重复 | 同一请求去重，不记多次学习 |

返回处理时重新授权；发送时获准不保证返回时仍有效。旧分支历史的标题和预览也不能在当前分支暴露未来事实。

缓存key包括上述范围和输入摘要，不能只按单词、任务ID或玩家最终答案共用私人反馈。相同材料的“解释一个词”和“完整解法”不能命中同一个无范围缓存。

默认诊断日志只记录请求ID、版本、类别、耗时、计费量与错误码，不记录全文、私人身份和完整剧情提示。需要提交问题样本时由用户主动确认具体范围。外部服务的数据保留、训练用途和删除能力以实际合同与能力核验，不承诺“撤回后供应商一定从未收到”。

本版不把玩家全文自动加入训练或产品语料。需要二次使用时另行明确同意、去标识和目的范围，不与获得基本反馈捆绑。

# 15. 故障、重试和费用（CAI-15）

## 15.1 有限失败路径

已保存草稿持续可编辑，网络不参与保存回执。每份当前草稿默认只保留一项主动评价请求；新修订不自动无限提交。

单次请求最多2次尝试，仅对短时服务错误/限流重试；权限拒绝、结构不符、过期正文、语义不确定不采用无上限重试。用户取消或预算不足就停止。界面始终提供本地帮助和显式行动确认，不以联网反馈为主线阻塞。

可设产品等待上限，例如30秒后停止等待并保持未评估；这是待测的服务设计初值，不是生成耗时保证。读写本身没有这个倒计时。

## 15.2 成本要算整条链

`总成本=输入用量×输入单价+输出用量×输出单价+实际重试+音频制作+存储/分发+人工审稿与试测`。

仅作算术示例：1000次请求、每次2000输入token和700输出token，对应200万输入与70万输出token；未包含重试与其他环节。没有填入价格，不代表账单或供应商报价。

实际选型时记录价格日期、模型版本、计量单位、预算上限和实测质量。不要只比较一次生成费用；返工、错误解释、重新配音和校准失效可能更影响总成本。

请求先预留上限，实际完成后按真实用量结算。传输重放不重复记同一次费用；真正重试是不同尝试，可能产生真实费用。候选被拒绝也不意味着供应商没计费。超预留费用应真实记账并触发停止新调用，不能让日志假装不存在。

不调用模型处理文件目录、数值比较、已知状态查询、词典精确索引、重复提示选择和奖励去重。模板与固定规则能可靠做的事，不为“用了AI”而改成推理调用。

# 16. 内容版本、发布和热修复（CAI-16）

## 16.1 同ID同版本不可变

同一资产ID+版本如果正文不同，构建直接失败，不能采取“最后加载的覆盖前一个”。英文、段落ID、中文、声音、字幕、题目、提示和校准依赖都记录精确版本及哈希。

原文排版容器改变与正文变化分别比较。第五与第十部分的五份Q-102复用属于原文相同，不能新增学习家族。对哈希/索引做任何规范化需要写明范围，不把删掉否定当普通清洗。

## 16.2 变更影响沿依赖图传播

原文变→派生译文、音轨、字幕、提示、测试和校准待核验。

题目或任务规则变→解法、提示、评分依据与校准待核验。

默认字幕显示变→听力暴露条件、独立记录与相应校准待核验。

纯颜色修改且未影响信息呈现→通常无需更改语言材料，但仍做可用性回归。

语义没有改变可以申请有依据的复核豁免，不能自动继承旧签核。不同角色签核只对相应范围生效。

## 16.3 已进入任务绑定旧包

新任务可以使用已批准的新包；进行中任务继续使用原绑定版本。资源清理不能删除仍被存档引用的必要包。加载失败不能偷偷替换成“最新版答案”。

普通更新使旧版superseded，但仍可供既有任务完成。安全、版权或严重无解问题导致quarantined时，停止新任务使用，对受影响存档说明情况并选择显式迁移/恢复；不能坚持使用已撤回危险内容，也不能静默重写世界历史。

迁移记录字段映射、设备检查证书、待提交预览、已执行回执、材料引用和学习暴露。已经合法完成的世界结果不因更新被取消奖励；未执行的过期预览必须重新核验。新稿不因ID变了就伪装成玩家首次见到。

## 16.4 发布签名与信任

文件哈希用于发现变化，不等于发布者身份。正式发布要有受控签核与可信发布清单，生产签名、密钥保管和原子安装由第十二部分确定。

测试代码把审核注册表作为可信fixture传入，只验证版本与角色约束，不实现真人身份鉴别或密码学签名。不能把一份能手工写入reviewed的JSON当真实审批系统。

## 17.1 Q-102完整交付演示

原公告给A/C条件，B规定给开泵与1.2米限制，船舶资料给1.4米和设备记录，电池说明给供应边界，录音修正灯本体/支架并限制许可范围。写作使用已有90—120词参考要求，不增加一篇“证明理解AI反馈”的作文。

本轮生成的受限请求示例只提取`Q102-R-NOTICE-p02`，没有发送同对象的答案与问题。手工示例返回only if局部说明，并验证引用切片。文件明确`model_call_performed=false`。

实际对玩家发布前，生产卡还缺真实音轨、真实复核、任务级难度与整合试玩。参考release gate会正确阻止当前候选作为player_release通过，而允许有未评估标记的内部检查。

# 18. 质量指标和缺陷优先级（CAI-18）

| 层面 | 观察什么 | 不用什么替代 |
|---|---|---|
| 叙事质量 | 角色动机、冲突、生活感、结果可见 | 生成字数 |
| 解谜质量 | 充分证据、多解认可、状态恢复 | 作者知道答案 |
| 语言质量 | 自然、准确、6.5任务适配、不同文体 | 生词密度和模型自评 |
| 音频质量 | 真实说法、清晰度、关键细节、字幕一致 | 脚本存在 |
| 在线反馈 | 有效问题精度、保义、合理表达接受、正确拒绝 | 自报置信度 |
| 系统稳定 | 重复提交、旧反馈、外发撤回、包版本 | 接口成功率一项 |
| 成本 | 每份可用内容成本、审校返工、延迟分位 | 单次推理便宜 |
| 学习效果 | 陌生材料、前后测、延迟表现 | 通关率与熟悉地图 |

阻断级：主线无解、事实责任改写、答案或私人范围泄漏、越权世界命令、假校准、重复奖励、真实数据丢失、缺音轨却记听力。

高优先级：语言明显不适配目标、关键听力漏词、错误建议改变意思、允许解被误拒、返回/无障碍路径阻断。

普通问题：冗余表达、文体不统一、装饰声音不佳、非关键布局。普通问题也要修，但不能用美术修复掩盖阻断问题。

模型语义回归至少分为正确表达、可接受变体、真实错误、模糊/缺信息、恶意或越权数据、隐私与剧透风险。训练示例和留出评估分家族隔离，报出样本范围和错误，不汇总成一个没有解释的“AI准确率”。
