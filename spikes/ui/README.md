# 原生输入试件

以 Godot 原生 TextEdit、Container 和 ScrollContainer 验证混排、长文、字号与键盘隔离。`--ui-test` 使用合成输入，结果不会写成真实输入法或读屏兼容通过。

人工操作：载入 3000 词样本；切换 200%；滚动到末行按钮；在正文中用中文输入法输入“雾海档案”，提交候选、撤销、重做；分别输入 WASD 和回车，确认场景计数没有增加；Tab 移到末行按钮；使用实际读屏检查正文和按钮名称。测试设备、软件、构建和每一步结果由 HV-001 记录。

Unicode 样本含中英文、重音组合、emoji、撇号与多行。3000 词样本是明确标注的压力夹具，没有语言难度校准含义。
