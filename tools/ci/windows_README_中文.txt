雾海档案：第七座灯塔 · 内部开发候选

解压完整文件夹，双击 MistSea-internal.exe。运行包自带 .NET 运行库；请保留同目录的 .pck、运行库和资源文件。

从岸边救援的零经验新档开始。候选内容包含序章、六个地区、终章和微光号的三个船舱。角色与场景目前采用灰盒呈现；双语材料、本地合成候选音轨和各章工作界面随包提供。

WASD 或方向键移动。选中物件，走近后按 E / Enter 交互。地图、任务、档案、队伍、学习、系统是六个常用入口。正文保存、确认意思和实际提交分别办理。关闭窗口时会等待正文保存；保存失败会保留窗口，供重试或导出当前正文。

生活委托在各地人物和现场工作台办理：旅舍订房、剧场演出、音乐盒修理、矿区换班、旧都的“给街道一个名字”“失物不是证据”，以及聚落的“两个天气预报”“借来的灯”等。先阅读当地合同，再核对实际物件、岗位、窗口和接收人；写完便条还需到场交付。微光号的观景处、档案台和工作台可打开“船上生活 · 当前人物与话题”，对话可暂停并恢复。

私人节点需明确邀请及当前许可。人物和现场界面会列出可办理事项；私人信件或记录仅在获准范围内打开，可暂缓或撤回邀请。已取得的材料可从档案回看，仍须符合当前权限。

六个地区另有 12 份独立可选安全合同。在对应现场取得完整合同，明确接受后选择独立战斗入口，并检查合同指定的备用设备。撤离可恢复该入口；完成这类合同不发经验、刻币或零件，也不替代主线塔站准备。

档案中的“离线查词”提供 720 个词义条目（360 CORE + 360 EXTENDED）；原文窗口也可选词查询。语境只来自当前实际取得并获准阅读的材料。点击“主动查看到期复习”可做本地复习或推迟复习。听力脚本可阅读；实际音轨需另行点击播放，阅读脚本不会记作已听。

正文窗口会提示保存状态；保存正文不会提交任务，关闭交付预览不会执行行动。修改正文、配置或许可后需重新核对和预览。系统页提供六个手动存档槽、“继续当前冒险”和“创建一致恢复备份”。读取旧检查点会建立冒险分支，学习记录继续保留；退出或换档前请等待当前正文保存成功。

系统页可调整 100%–200% 字号，以及主音量、内容语音、环境声、音乐和界面音。默认存档位于 Godot 用户数据目录。在线供应商默认关闭。

包内 VERIFICATION.json 记录实际执行的工程检查范围；PACKAGE_MANIFEST.json 列出文件哈希。包内内容检查会核对编译清单，并实际解码 WAV。工程检查之外的人工输入法、读屏、审校、审听、6.5 条件校准及另一台干净 Windows 设备验收仍待完成。

此包供本地开发验证，正式发行及发布者签名尚待审核。读、听、写按 6.5 目标设计，通关不产生 IELTS 认证或考试分数承诺。
