## 实际覆盖

身份唯一、场景引用、继承角色与战术层级、个人任务依赖、350经验预算与0额外运输奖励。有限话题视图在角色知情和发布门未满足时裁剪；D-1时间范围与来源保留。受控发送检查字段、接收方、用途、版本、确认与过期预览；重复命令和重复投递槽不创建新消息。关系不接收语法/礼物/情绪评分事件；分歧、暂停、重新协商和已核验失约分别处理。安全离队归还装备，岗位互斥，援勤补位不复制。六地区双职能、当前协议和不同回执被检查。

1,296来自四同伴三种已表态观点(3^4)与四人招募/不招募(2^4)的组合。每种都核对相同技术条件下的两条或三条结局资格不因这些状态变化。32来自五项增强准备的真假组合；只有全部成立时多出分布式选项，基础条件仍另外检查。

这些不是1,296次全游戏通关，也不是50场玩家试玩。资格函数没有社会参数，只说明这个接口保持了独立性，不能证明所有间接工作路径已经可达。

## 具体边界

内存提交不证明磁盘崩溃原子性；资料许可对象假设来自可信上位规则，不能证明认证安全。固定安全回复不证明实际语言模型不会泄漏。身份/地点登记不证明寻路或全局NPC并发。文章与脚本均未进行6.5人群校准，未配音。个人节点是契约，不是12个已运行关卡。终局完整战斗仍继承第八部分的未验证事项。

## 复现

```bash
python validation/run_validation.py
```

日志为`validation/run_log.txt`，机读结果为`validation/validation_report.json`，结构化例子为`validation/scenario_traces.json`。运行日期仅用于核对本次执行，不是开发工期或未来完成承诺。
