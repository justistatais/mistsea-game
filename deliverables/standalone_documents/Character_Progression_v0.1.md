## 文档地位与范围

本部分确定RPG成长的组织、属性预算、天赋路线、装备与资源归属、一次结算及后续战斗接口。体验与权限规则作为本版设计基线；具体伤害系数、价格、经验分配与装备数量是**可执行的原型初值**，不是经过整场战斗或用户试玩验证的平衡结论。

英语仍以Academic阅读、听力、写作各6.5为固定目标。本文件不重新定义官方分数，不把角色等级或战斗效率换算成英语水平。不因为玩家开字幕、查看翻译或使用辅助写作，减少基本任务奖励。

本轮提供36个天赋节点、28件核心装备定义、8个改件定义、4种个人增强补给、32条主线奖励预算、六塔物资与人员容量约束。此处不是全部物品美术、角色动画或已实现的战斗引擎。代码只覆盖明示的数学、引用、预算与局部状态规则。

上位文件中的“战斗提供资源取舍”“培养队伍”等在此具体化；不增加新的主线解谜前置。详细回合、敌人、首领、同伴技能与战斗状态语义由第八部分结合本契约完成。需要改变这里的基线，必须记录变更，不能在代码里默默另写一套。

# 1. 成长要带来什么（RPG-01）

成长的直接回报是：玩家发现新打法，能更好地安排伤害、防护、装置和队友；返回旧地区时保留实力优势；获得新的装备外观与横向效果；能免费改变路线尝试另一种方法。

不设计“英语越好伤害越高”“答错题扣等级”“读满十份材料才能学技能”。任务经验来自完成真实冒险工作，战斗、停机、潜入等同等结果共享主目标奖励。

四层进展分别记录：角色等级控制通用数值和点数；职业阶位来自剧情认可与装备校准；构筑是玩家的属性、天赋和装备选择；语言能力在第五部分独立记录。六塔准备是世界工程状态，不属于角色战斗力。

高等级可以减轻普通战斗压力，但不能抹去关键证据需求，也不能用伤害直接跳过首领的必要操作阶段。属性不授予读心、测谎、自动翻译或全知地图。

# 2. 等级、经验与点数（RPG-02）

起始等级1，上限30。五项属性基础值均为5，创建时获得4点自由属性，此后每升一级再得2点；单项上限25。允许暂不分配，也提供可见的推荐分配，但不暗中代替玩家加点。

从等级L到L+1所需经验为 `100 + 40×(L−1)`。到达等级L的累计门槛为 `100×(L−1) + 20×(L−1)×(L−2)`。30级门槛19,140。

技能点：1级0点；2级获得2点；此后4、6、8……30级各获得1点。即L≥2时 `1 + floor(L/2)`。30级共有16点。剧情阶位不再额外赠送技能点，避免两个来源重复计算。

30级累计自由属性点62，技能点16。所有获得来源由回执推导；洗点退还已经获得的点，不重新触发“升级奖励”。满级后的既有经验记录可保留，但不自动转成无限金币、额外属性或外部英语成绩。

各章只走主线的经验与等级如下。表中是章末结果，不是地图最低入场等级。玩家可以提前有支线经验，不触发动态追平怪物。

# 3. 职业阶位与装备校准（RPG-03）

阶位是玩家完成实际工作的社会认可，装备校准表示同一类个人装置获得统一配置。它们由主线回执派生，不要求刷到某级再去找一位可能失联的NPC，也不要求付钱重新领取。

任务授权仍由任务世界授予，不能用一个高阶位字符串冒充检修许可；学会技能也不等于取得档案访问权。

# 4. 属性的实际用途（RPG-04）

不设置智力、英语天赋、词汇战斗力或需要识别真实谎言的数值。英文世界内容与学习目标不随加点变化。

| 属性 | 主要战斗作用 | 探索的允许作用 | 禁止作用 |
|---|---|---|---|
| 体魄 | 生命上限、基础防御效果 | 改善已说明的环境/搬运容错；没有该加点仍有安全替代 | 不能用高血量穿过未建立规则的致死剧情 |
| 力量 | 近战主系数、失衡压力 | 在有替代手柄或协作的可选障碍中改变方法 | 不能掰开所有剧情门、代替线索 |

| 专注 | 技术主系数、战斗资源上限 | 改善明确的个人装置使用能力 | 不成为看字幕、查词或暂停的次数 |

## 4.1 基础算式

设等级为L，校准阶g，体魄B、力量S、敏捷Agi、感知P、专注F：

- 最大生命：`80 + 8×(L−1) + 6×(B−5)`。
- 最大战斗专注：`min(14, 6 + floor((F−5)/4) + 装备加值)`；无装备时范围6—11。
- 先手：`10 + floor((Agi−5)/2) + 装备加值`。平局规则留第八部分，不能依赖鼠标反应。
- 公共输出底数：`12 + 2×(L−1) + (8+8g)`。
- 近战输出：公共底数 `+0.8×(S−5)+0.4×(Agi−5)`。
- 远程输出：公共底数 `+0.8×(Agi−5)+0.4×(S−5)`。
- 技术输出T：公共底数 `+0.8×(F−5)+0.4×(P−5)`。
- A表示所持武器所用类型的输出，可能是近战、远程或技术；天赋写T时固定按专注与感知计算。
- 使用已经成立的“暴露”时，加成为 `5% + (P−5)×1% + 明示追加`，上限40%。属性不自动制造暴露。
- 主动基础防御为 `20% + (B−5)×0.5% + 明示追加`，所有临时减伤最终取最大，最高35%。

力量对明确存在的失衡压力按 `floor(基础压力×[1+0.02×(S−5)])`计算；来自技能、武器和改件的基础压力先合并，每个动作最多6点。没有失衡来源的动作不凭空产生压力。阈值、首领抗性和失衡后果由第八部分确定，绝不等于自动打断所有动作。

在默认框架下，不引入基础随机未命中和独立随机暴击。命中合法性、保护状态和抗性仍需检查；暴露是明确战术状态，不是英语答对奖励。

## 4.2 加成不能无限乘

通用伤害加成同池相加，上限50%；暴露另池上限40%；装备减伤上限45%；临时减伤取各来源最大而非全部相乘，最高35%；护盾数值加成同池最高50%。

例如，已经有20%的防御，不会因另一名队友提供15%临时减伤就变成35%；按较大的20%执行。装备减伤与这一项分别结算。

护盾不做算术堆叠：取旧剩余护盾和新护盾的较大者，总量最多目标最大生命的50%。重新施加可以按明示规则延长到较晚的有效期限，较弱护盾不覆盖掉较强剩余值。盾到期、吸收和倒地关系在第八部分完成。

同一动作对同一目标的多段系数先汇总，统一处理一次暴露消耗、一次该类触发和最终取整。不能用“分成五次”把一次遗物效果触发五遍。

上述规则限制了失控叠加，但不证明三个路线已经平衡。实际输出、承伤、行动效率仍要在第八部分用敌人与队伍验证。

# 5. 天赋学习与装备规则（RPG-05）

三个路线各12节点，共36节点。每节点1点、单级，不设计同一技能连续点五次只加伤害。

每路线六个主动、六个被动。四个主动槽供玩家编排，基础攻击、防御、物品、救起、场地交互不占天赋槽。已学被动全部生效，不再收取第二次“被动装备税”；因学习点有限与叠加上限，无法学满三树。

技能学习不是职业锁。所有路线都可以使用三种基础武器，使用何种主属性会在预览中展示。等级不足、前置不足、点数不足时说明具体条件，不用读完教程或答对英语题作前置。

T1最低2级，无树内点数门槛；T2最低8级且此前本树已投入2点；T3最低16级且此前投入5点；T4最低24级且此前投入8点。各节点同时要求表中的直接前置。

检查整套洗点提案时必须能按合法顺序重新学到全部节点，不允许用未合法取得的高层节点反过来凑前置点。四个主动槽最多装备一个终阶主动；16点正常预算也不足以学习两套最小终阶路径。

## 5.1 战斗接口初值

主角每回合3AP，敏捷不加AP。基础攻击2AP，防御1AP，一般场地交互1AP。主动技能费用见表。战斗专注开场满，之后每个自身回合开始回复1点；它与现实注意力、查词次数无关。

技能在自身回合t使用、冷却c，下一次可用为t+c+1。即“冷却1”需要隔过一个完整自己的回合，不是下一回合就能再放。特定技能减费后至少支付1点专注，原本0费用的基础动作仍为0，不反向生成资源。

返还专注类触发全体合并：每个自身回合最多1点，每遭遇最多2点；自然回合回复和付费补给按各自规则，不计入这个触发预算。任何效果都不返还AP。

个人装置初始最多1件，学会M08后2件。一个敌方攻击动作最多触发同一施放者的一件装置；装置与各类一次性被动有稳定实例和遭遇计数，不靠切装备重置。

无特别写明时护盾到来源角色第二个后续“计划内回合开始”结束；倒地/跳过的计划回合仍推进计时，不让时钟暂停生成永久盾。遭遇结束清理临时状态。第八部分必须统一实际状态生命周期，不将本文自然语言直接当成可执行代码。

# 12. 同伴成长与无人入队的兜底（RPG-12）

四名剧情同伴共享主角等级与校准，不分走经验，不因留在船上停止成长。第六章才加入的泰丝直接按当前等级与个人模板取得可用战术，不需要回低级区练级。

每位同伴两项基础行动；等级12、20、24分别开放一个战术变体选择，具体行动与节奏由第八/九部分定案。本轮只实现预算合法性的模板参考，不声称已经设计完四人的全部技能。

每名同伴允许一个个人遗物槽，共用真实收藏实例，不复制主角的同一遗物。可在安全处改配，明确显示它将从谁身上卸下。

Q-101后在合法出发点提供两类通用地方援勤模板：护卫和支援，用于补足最多两个队席；不占四名同伴的剧情身份，没有私人支线，也不产生全知技术。主线证据不依赖雇用某位角色。序章按当时可用援助单独设计。

标准战斗以后按“主角+两席可用援助”的可靠配置验证；玩家主动关闭援助属于明示自选挑战，不是默认暗中提高难度。地方援勤、六塔值守岗位和安装班组分别登记，不是同一NPC同时出战与施工的复制品。可以不带任意一名剧情同伴，不能因此失去主线必需物品、工程人员或结局资格。

# 13. 洗点、换装、保存与权限（RPG-13）

安全区域或正式战前整备可以免费完整洗点、改变技能、换武器、转移改件和设置遗物。既有升级点总额不变，不消耗稀有洗点石。功能从第一次获得技能点起可用，不依赖一个已失踪导师的服务。

默认允许保存三套玩家方案，内置推荐配置另列。预览先显示属性变化、学习前置、槽位、物品占用与失去的被动，再一次提交整套变化。

退款一个低层前置时，要么同步退款受影响后继，要么明确提示并拒绝部分非法状态。不能临时留下无前置终阶技能。升级后新点先未分配，玩家开启自动分配才按可见规则投入。

战斗中不换装、不洗点、不增删主动/被动；加载和界面开关不改变当前遭遇的冷却、装置或一次性预算。安全区换装因为下次遭遇按完整状态开始，不存在靠反复卸下加血装备偷偷回血的额外收益。

战前属性与道具是冒险存档的一部分；学习档案保留暴露史，但不充当全球禁领奖单。角色读取旧分支时，只使用那个分支已有装备与奖励，不能继承另一分支已买的物品。纯主线最后取得的30级属于终局结果；读回起航前存档仍为当时的28级。希望终局前使用满级配置，可通过已声明的可选经验提前达到，不能把通关点数逆向带回旧分支。

装备未知版本或非法存档需保留原数据并提供迁移/恢复，不静默销毁独特物品。具体存储、槽位和磁盘事务由第十二部分实现。

# 15. 奖励提交与反复制（RPG-15）

使用第四部分的任务实例与规范结算槽，旧reward_ref映射到本轮定值；不是注册另一份新的奖励叠加到旧TBD上。Q-102已有REWARD-Q102-RESOLUTION保持对应同一工作的权益。

世界结果、经验/货币、装备取得、相关校准回执与通知记录共同提交；动画可以补播，奖励不可补发两遍。等待领取的奖励由权益ID保存，背包/画面满不阻塞剧情，也不消失。

同一结算请求重试返回原回执；换一个请求ID仍不能对相同任务结果再领一次。读回结算之前的存档，则那个分支正常重新完成并得到一份，不能用全局学习记录阻止。

新练习编号、换人名和重复战斗不产生新的主线权益。收藏重复物品不换算成钱；免费补给、借用工程物资和装备转移没有可被回售的新增实物。

角色数值不得写入最终航道答案、材料已理解状态、NPC责任或六塔完成。反过来，模型文字、NPC一句表扬或英语成绩，也不得直接写入角色经验与钱包。

# 16. UI与实际操作（RPG-16）

成长页面保留等级、下一升级进度、已得/未分配属性点、技能点与阶位，不用一个综合战力覆盖全部选择。

属性预览显示增加前后数值，例如“体魄+1：最大生命+6，防御+0.5个百分点”。专注属性距下一容量台阶还差几点明确可见，不能用四次加点只变一次数字让玩家猜。

技能树显示层级、直接前置、已有投入、费用、冷却含义和作用对象。设备操作说明、角色加点、商店价格与错误提示默认中文，可切英文；这不是新增的一套强制学习题。

装备对比按当前校准显示：旧武器不会显示未校准值来诱导购买新物品。装备减伤和临时减伤分开，显示到上限后哪些加成不再增加。

战前界面同时列出主角方案、两席援助、已占用遗物/改件、2次基础配发与2格增强补给。标准战斗与语言支持独立设置。

工程库存有独立入口和单位；明确标明已预留、运输、安装和待核验，不能和个人“零件55个”混成同一计数。

# 17. 最低版本、样章与完整版（RPG-17）

机制原型先实现1—4级经验与属性、免费重配、三种起始武器、基础防具、每树前两个主动（六个主动）、通用行为与RE-01。Q-102结束开放的第3个点若已有T1被动实现则可使用，否则明确暂存，不假装生效。

第一可玩样章扩展到1—6级、三树完整T1九节点、一次校准、3件基础武器、3件基础防具、2件保证获得的遗物、TL-01和至少一类I改件。样章的第二/三级节点可以预览但不制作假演出。

完整版按36节点、28核心装备、8改件、4付费补给及完整主线预算实施。先验证基础循环与数值字段，再扩展词条数量，不先制作数百件随机装备。

同伴完整技能和敌人并非本轮交付；第八部分必须结合本轮属性与资源规则补齐。三个支持入口不能在低成本原型中被删成“只准战斗拿经验”。

# 18. 给第八与第十二部分的接口（RPG-18）
