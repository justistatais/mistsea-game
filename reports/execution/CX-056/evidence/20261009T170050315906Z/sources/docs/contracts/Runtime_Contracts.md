# 内部运行契约 v1

Godot 客户端在组合根接入 Application 和 Infrastructure。Core 只依赖 .NET，保存规则与不可变数据；SQLite 和文件操作留在 Infrastructure。Python 用于制作、构建和证据整理，游戏运行不调用参考 Python。

Profile、Branch、LoadContext、Command、Receipt、Draft、Attempt 使用不同强类型 GUID。内容定义沿用原 ID，并以定义版本和精确 release_id 绑定。恢复到旧检查点会新建分支、继承当时回执并更换加载令牌；继续读取当前分支也更换令牌，但不新建遭遇。读投影不推进动作时钟。墙钟用于日志，剧情时钟由明确动作或战斗槽推进。

JSON 使用 snake_case，拒绝重复字段、未知 DTO 字段和整数枚举。持久格式为 schema 1。高于当前版本的数据库拒写；升级必须先生成一致迁移候选。正文只统一换行，不进行 NFKC，段落偏移以 Unicode scalar 为单位。

世界写入经过专用单写线程。Application 的 ValidatedPlan 在事务内重新检查相关版本、物品归属和余额，原子提交实体、物品、余额、回执、命令记录、outbox 和分支序号。命令 ID 绑定请求哈希；语义结算槽限制同一工作在同一分支领取一次。outbox 只显示已提交事件。

草稿是不可变 revision，任务/分支的 head 采用 CAS。只有事务提交后才返回 DraftSaved。删除后旧 head 保留墓碑，新写入分配新 DraftId。删除控制存于独立 control.sqlite：先提交世代和墓碑，再清理正文/学习数据。所有墓碑在旧备份恢复时重放；世界回执不因删除正文消失。控制库缺失时停止写入。

语言目标固定 R/L/W 6.5，Speaking=null，自动升档关闭。观察只记录实际模态、帮助、家族、尝试和来源，播放完成不推断理解，字幕不算纯听力，结构化选择不算独立写作，未校准时不输出 band。

IAssistanceProvider 只接受明确材料片段和请求正文，不拥有 IWorldCommands。默认 DisabledProvider。外发需要显式确认，晚反馈按世代、同意版本、分支、加载上下文和草稿版本路由；失效反馈丢弃，不修改世界。

九类源适配器沿用 part03—11 的字段契约。旧奖励标识对应第七部分真实奖励；不存在的映射阻断编译。普通材料只投影题干段落，不投影示范答案。正文 ID/版本/哈希历史防止同版本换文。内部候选与正式检查分开，音轨、人工审核、6.5 校准和权利签核缺失时不能正式发布。

包安装先暂存并验证声明尺寸、路径、类型、SHA-256、精确依赖和可信发布者签名，再切换版本指针。内部无签名包必须显式允许。哈希不表示发布者身份；测试生成的 RSA 密钥只用于测试，不是项目发布授权。隔离内容包保留原存档和修复方向。
